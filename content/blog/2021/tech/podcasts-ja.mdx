### ポッドキャストとは
+ 狭義では、一般に独立したポッドキャストを指す。前述の海外での制作手順に沿い、分散型で配信し、すべての内容を自分で管理する。そのため、自分のホスティングサーバーとドメインを持ち、RSS 購読 URL にそのドメインを含める必要がある。サーバーが停止しても、固定の RSS リンクからリスナーが見つけられる。
+ ポッドキャストはデジタルメディアで、音声、動画、電子ラジオ、テキストなどを一覧としてインターネットに公開する。利用者は端末から購読し、ファイルをダウンロードまたはストリーミングして受け取る。Podcast は iPod と broadcast の合成語だ。
+ 簡単にいえば音声番組である。通常はオリジナルの音声・動画番組だが、テレビ、ラジオ、講演、パフォーマンス、その他のイベントの録画を配信することもある。世界中で制作される、完全に無料のコンテンツだ。
+ 2005 年、Apple CEO の Steve Jobs は「Podcasting は次世代のラジオである。利用者は 3,000 以上の無料 Podcast を購読でき、新しいエピソードはインターネット経由でコンピューターと iPod に自動配信される」と述べた。2020 年には iTunes Store で 100 万を超えるエピソードを選べ、世界に 75 万以上の独立したポッドキャストがあった。配信先もコンピューターや iPod だけでなく、スマートフォン、スマートウォッチ、スマートスピーカー（Alexa、HomePod）、CarPlay、RSS などへ広がった。

**Polkacast : A decentralization podcast hosting platform**

### Polkacast とは
+ Polkacast は Substrate、IPFS、Ethereum のスマートコントラクトなどを統合した BaaS（Blockchain as a Service）だ。便利で素早く簡単に収益を得られるホスティングを制作者に提供し、高度なコミュニティ自治と TOKEN 経済を目指す。広告以外にもプラットフォームの TOKEN や発行権を通じて追加収益を得られる。BaaS はコミュニティ統治、拡張性、分散性、スマートコントラクトを備えた NATIVE WASM アプリであり、独立制作者と利用者に好まれる制作・配信プラットフォームを目指す。

### 成長の経路
+ スマートスピーカーの普及がオーディオブックとポッドキャストの成長を後押しする。2020 年、米国と中国の都市部では普及率が 25% を超える見込みだった（36）。他の地域が追いつくにつれ、さらに高い成長が期待された。米国の所有者の 66% が、少なくとも週に一度オーディオブックやポッドキャストを聴くと答えている。
+ ワイヤレスイヤホン：米国の若者はほぼ一人一組を持ち、移動中の音声利用を便利にする。2019 年の世界の TWS 販売は 1.1 億台、2020 年は 1.4 億台の見込み。2026 年に 1182 億元、年平均成長率 10.6% と予測されている。
+ コネクテッドカー：利用者の約 10% は毎日車内で CarPlay や Android Auto を通じて聴いている。

### Polkacast の特徴
+ Polkadot の共有セキュリティで、耐障害性、フォーク不要の更新、拡張性、クロスチェーン、高度に統一されたオンチェーン統治を実現する。
+ Ethereum のスマートコントラクトで TOKEN を公平に分配し、DAO の統治を行う。すべての制作者に投票権と統治権がある。
+ IPFS のストレージで信頼できる BaaS ホスティングを構築する。
+ 制作者が収益を得られる、永久無料のホスティング。
+ ログインやソーシャル機能のない汎用クライアントで、プライバシーを最優先する。
+ Apple Podcasts、Spotify、Stitcher、TuneIn、iHeartRadio、Google Podcasts など、各プラットフォームへ自動配信する。

### Polkacast のビジョン
+ Polkadot のパラチェーンとなり、成長するクロスチェーン環境と共有セキュリティを利用して、よりよく安全なコミュニティ自治サービスを提供する。プライバシーを守り、収益を生む分散型プラットフォームを作る。
+ ポッドキャストの意味は、誰もが自由に意見を表し、自分を見せられることにある。独立性が最大の魅力だ。個人は意見、企業は価値観を発信する。各人や企業が独自の特徴とスタイルで番組とブランドを作り、成功するかはコミュニティが決めると信じている。

### Polkacast のエコシステム
+ DAPP 版の汎用クライアント。
+ Polkacast ベースの BaaS サービス。
+ 制作者の通貨発行権。

### まとめ
+ Polkacast は純粋な分散型ホスティングだ。ポッドキャストの発展が進めば、分散型を必要とする制作者も増えるだろう。ブロックチェーンにも TOKEN 経済を与え、情熱で制作する人にささやかな収益と収益化の手段を提供したい。
