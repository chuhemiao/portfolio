>問題の調べ方がまだ雑だ。経験不足なのか、努力不足なのか。上司が来て少し説明しただけで解決してしまった。Google のブラウザーで複雑な AJAX リクエストを見てため息が出た。以前は本当に読み方がわからなかった。Firefox の Firebug は使えていたのに。やっと Chrome の使い方がわかったので、今回の問題を書く。まず、AJAX のコールバックでは、この状況で return false と書いても機能せず、ずっと失敗していた。さらにフォームの送信には onsubmit="ラップした関数" を使い、ユーザー名、メール、CAPTCHA などを検証していた。そこで問題が起きた。同時に二つのフォームを送信していて、成功するはずがない。リクエスト先の URL を見て、自分の間抜けさに気づいた。なぜそのとき思いつかなかったのだろう。
