## Share to social media with the share.js plugin

1.For the tutorial, see[overtrue](http://overtrue.me/share.js/)

2.Image caching problems when sharing to Facebook

+ Clear the cache:`https://developers.facebook.com/tools/debug/`
+ ![facebook](https://source.shengxuezixun.com/facebook_clear.png)

3.After clicking debug:

+ ![facebook](https://source.shengxuezixun.com/fb_url.png)

4.Try clearing it several times. If that does not work, specify the image directly.

			<head>
			<meta property="og:title" content="梦遥奇缘" />

			<meta property="og:description" content="梦遥奇缘 " />

			<meta property="og:url" content="http://idiot6.com" />

			<meta property="og:image" content="//source.shengxuezixun.com/images%2Flogo.png"/>

			<meta property="og:type" content="website" />
			</head>

5.Return to the page you want to share and click Share. It should now use the specified image.

## ps: Using`share.js`issues

1.If you cannot specify social sharing services on iOS, check whether you are using the jQuery version. The native JavaScript version only displays your specified sharing services on Android.
