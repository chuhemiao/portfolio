## Bottle
+ Bottle is a Python web framework contained in a single file of a few dozen KB. Despite being small and lightweight, it includes routing, templates, simple database access, and other web framework components. It is a usable framework worth trying when learning web development: the syntax is simple and deployment convenient.
+ Bottle means a bottle, and its icon includes one. You can build small websites and APIs in seconds. The entire framework is a single py file, and extensibility was considered in its design, allowing more advanced features to be added.
## tqdm
tqdm (pronounced taqadum) means progress in Arabic. It adds progress information to long loops: simply wrap an iterator with tqdm(iterator). It is a fast, extensible progress-bar library.
Simply put, tqdm is a fast, extensible progress bar for Python.
## pyvim
You probably know Vim. pyvim is a Python version, or clone, of Vim. The editor is developed entirely in Python without C extensions, making development much faster. It is easy to prototype and integrate new features.
## pyglet
+ pyglet provides an object-oriented programming interface for games and visually rich applications on Windows, Mac OS X, and Linux. Written entirely in Python, it is a cross-platform framework for multimedia and windowed visual-effects applications. It is released under the BSD license and can be used in commercial and open-source projects.
+ It also works without extra dependencies, supports multiple windows and monitors, and can load images, audio, music, and video in any format.
