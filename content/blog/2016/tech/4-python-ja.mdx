## Bottle
+ Bottle は、数十 KB の一つのファイルに収まる Python の Web フレームワークだ。小さく軽量だが、ルーティング、テンプレート、簡単なデータベースアクセスなどを備え、十分使える。Web 開発の学習に試すのもよい。構文が簡単で、デプロイもしやすい。
+ Bottle は瓶という意味で、アイコンにも瓶が描かれている。小規模なサイトや API を数秒で作れる。フレームワーク全体は一つの py ファイルで、拡張性も考えて設計されているため、高度な機能を追加できる。
## tqdm
tqdm（発音は taqadum）はアラビア語で進捗を意味する。任意のイテレーターを tqdm(iterator) で包むだけで、長いループに進捗表示を付けられる。高速で拡張性のあるプログレスバーのライブラリだ。
つまり、tqdm は Python 向けの高速で拡張可能なプログレスバーだ。
## pyvim
Vim を知っている人は多いだろう。pyvim は Python で作った Vim の版、あるいはクローンだ。C 拡張なしで完全に Python で開発され、開発が速くなる。プロトタイプや新機能の統合もしやすい。
## pyglet
+ pyglet は、Windows、Mac OS X、Linux でゲームや視覚効果の多いアプリを開発するためのオブジェクト指向のインターフェースを提供する。純粋な Python で書かれた、マルチメディアやウィンドウ表示向けのクロスプラットフォーム・フレームワークだ。BSD ライセンスで公開され、商用・オープンソースのプロジェクトで使える。
+ 追加の依存関係なしで使える独立性があり、複数ウィンドウとモニターに対応し、あらゆる形式の画像、音声、音楽、動画を読み込める。
