## Markdown で見出しを付ける二つの方法
+ 一つ目：文字の下に「=」や「-」を入れる。それぞれ第 1、第 2 レベルの見出しになる。
+ 二つ目：文字の先頭に「#」を入れ、その数で見出しのレベルを示す。レベルは 1～6 で、1 が最も大きい。
## 文字の強調
+ *斜体* or _強調_
+ **太字** or __太字__
+ ***太字の斜体*** or ___太字の斜体__

## コードブロックをすべて表示する
+ 三つのタブ、または次を使う：`<ul>コードブロック</ul>`
+ 複数行のコードなら次を使う：```php
phpinfo();
```
## 引用
+ > または >> を使う。ただし >> の前には空白が必要
