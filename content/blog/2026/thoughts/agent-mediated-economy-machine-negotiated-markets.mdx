## TL;DR

**B2A 问的是企业把东西卖给谁；更重要的问题是，当买卖双方都通过 Agent 参与市场，市场本身会变成什么样。技术可以降低协调成本，却无法自动决定效率收益归谁。**

- **Agent 是一次新的交易成本下降。** 互联网降低了搜寻成本，但评估、协商、执行与追责仍主要靠人。Agent 可能同时介入这些环节 —— 真正的变化不是每笔交易都自动完成，而是**大量因协调成本过高而从未发生的交易，变得在经济上可行**。
- **但它不会让交易成本归零。** 它引入了模型调用、错误执行、身份验证、欺诈防范与责任认定这些新成本。只有节省的持续高于新增的，新的组织方式才有长期竞争力。
- **最重要的制度问题是：Agent 到底代表谁。** 当商业推广被嵌进任务规划与工具选择，利益冲突比传统广告更难察觉。谁有权定义 Agent 的目标函数，决定了它是消费者的代理人，还是平台的分发工具。
- **搜索不再稀缺时，可信度成为新的稀缺资源。** 面向机器优化的商业信息同样会造假，而且造假可以自动化。关键基础设施不是更强的推荐，而是可验证的经济事实、授权与责任。
- **Agent 时代未必是去中心化的胜利。** 用户越多、商家越多、工具越多、完成率越高，网络效应越强 —— 少数 Agent 平台可能成为新的经济协调中心。效率提高和市场集中可以同时发生。
- **现实仍在早期。** 公开的 Agent 流量数据一再显示，绝大多数请求停留在浏览与搜索页，到达结账环节的只有百分之二三。Agent 已经在改变信息发现，自主交易明显落后。

> **核对说明**：文中 2026 年的产品与数据已逐条核对，三处按原始来源改写。① OpenAI 的 Businesses in ChatGPT 于 11 月 10 日以 **beta** 形式上线，Business Agent 首批只开放给**美国**的电商与在线服务企业。② Universal Commerce Protocol 是 **Google 联合 Shopify 等零售商**推出的，不是 Shopify 单独推动。③ 原稿引用的 HUMAN Security「10 月 Agent 浏览流量较 8 月增长约八倍、85.2% 停留在浏览与搜索、1.9% 到达结账」**未能找到原始报告**；HUMAN 公开可查的数据是 2025 全年 77% 落在商品与搜索页、2.3% 落在结账页，2026 年 4 月月报中结账与支付占 3.16%。量级与原稿的论点一致，正文改用可查的数字。另需注意 HUMAN 报告里另有一个「八倍」，指的是自动化流量的增速是人类流量的八倍，两者容易混淆。

## 引言：未来的交易，可能不再需要人类亲自参与

设想几年后的一个普通早晨。你准备去日本生活半年，需要租一套公寓、买保险、办网络，再配一套远程办公设备。你没有打开房产网站，也没有逐个比较保险报价，更没有分别注册五六个平台。你只是告诉自己的 AI Agent：

> 未来六个月我住东京，预算每月 25 万日元以内，离地铁站步行不超过十分钟，需要稳定的网络和适合远程工作的环境。帮我安排好，但所有长期合同必须经过我确认。

你的 Agent 向多个房产服务商的 Agent 获取房源，验证租赁条件，比较保险方案，检查网络覆盖，并请求可执行的报价。商家的 Agent 则根据库存、履约成本、客户条件和交易规则，决定是否提供服务、如何报价。**双方交换的不再只是网页信息，而是可以被程序验证的商业条件、授权凭证和交易承诺。** 你最后收到的不是几十个等待浏览的网页，而是一份已经核验、比较、准备好预订的方案，只需批准其中涉及长期责任的部分。

这个场景尚未普及，但它提出了一个值得认真对待的问题：**当人类逐渐把搜寻、比较、协商和执行交给 AI Agent，市场还会按原来的方式运行吗？**

2026 年 11 月，a16z 的 Olivia Moore 和 Justine Moore 提出 **B2A（Business to Agent）**，认为 AI Agent 正在成为企业的新用户和新的分发对象。这个判断抓住了一个重要变化，但它沿用的仍是传统商业模式的分类方式：企业向谁销售？真正值得追问的是另一件事 —— 如果买卖双方都通过 Agent 参与市场，价格如何形成，信息如何传播，交易如何达成，信任如何建立，市场权力又掌握在谁手中？

这已经超出了 B2A 的范畴。我倾向于用 **Agent-Mediated Economy（AME，Agent 中介协调经济）** 来描述这种可能出现的结构。它不是一种独立于现有经济的新经济，而是一种正在形成的**市场协调机制**。核心变化不是 AI 成了新的消费者，而是**人类把经济活动中的部分决策权与执行权，委托给能够持续运行的软件代理**。如果这一变化被广泛采用，我们见证的就不只是分发渠道的又一次迁移，而是市场中介方式的一次重组。

## 一、市场的本质，从来不只是买卖

要理解 AME，先要回答一个经济学问题：为什么人类需要市场中介？

最简单的模型里，买方有需求，卖方有供给，价格协调双方。现实远比这复杂。买一辆二手车，你要找卖家、确认车况、比较价格、协商合同、安排支付，还要承担交付之后的问题。这些行为本身不生产汽车，却消耗大量时间、知识和资源。

1937 年，罗纳德·科斯在《企业的性质》中指出，**使用价格机制本身是有成本的**，这一思想后来发展为交易成本经济学。市场之所以需要企业、经纪人、平台、银行和各种中介，很大程度上是因为它们能降低交易摩擦。

从这个角度看，几百年的商业技术史就是交易成本持续下降的历史：工业化降低了生产和运输成本，电信降低了远距离沟通成本，互联网降低了信息传播和搜寻成本，电商降低了在线交易和支付成本。但互联网始终没有真正解决一个问题：**信息变得容易获得，理解信息、判断选择和执行交易，仍然主要依赖人。** 互联网解决的是信息如何抵达人，没有解决信息如何转化为行动。

这就是 Agent 可能带来的制度性变化：传统互联网提供信息入口，**Agent 可能成为连接需求表达与经济行动的执行中介**。

## 二、从信息经济到行动经济：一次新的交易成本下降

可以把一笔交易的总成本粗略拆开：

```text
总交易成本 = 搜寻成本 + 评估成本 + 协商成本 + 执行成本 + 监督与追责成本
```

这不是可以统一计量的公式，而是分析交易摩擦的框架。过去二十多年，互联网大幅压低了第一项，后面几项却没有同比例下降。一个人十分钟就能找到上百家提供相似服务的公司，却仍要花几个小时判断哪家可信、哪家真的符合需求；更复杂的交易还要沟通、议价、支付和反复确认。

Agent 的潜在价值在于它能**同时介入这些环节**：搜索供应商，按事先确定的规则比较服务，调用接口获取报价，检查合同条件，并在明确授权下完成部分执行。以信息流转为中心的交互，有机会扩展为**以任务完成为中心**的交互。用户买的可能不再是访问某个软件的权利，而是一个可以验证的任务结果 —— 未必愿意给五个旅行规划软件分别付订阅费，却可能愿意为一次完整可靠的跨国旅行安排付服务费。企业也可能不再按席位收费，而是按成功完成的订单、验证通过的任务或实际节省的工作量收费。

但有一个重要约束：**Agent 不会让交易成本自动归零。** 它降低了人工搜寻与执行成本，却引入了模型调用成本、错误执行成本、身份验证成本、欺诈防范成本和责任认定成本。只有节省的持续高于新增的，新的组织方式才有长期竞争力。这也是为什么 Agent 会先在软件开发、标准化采购和低风险信息处理中普及，而医疗、金融和复杂法律交易需要更谨慎的制度安排。

**真正的变化，不是每一笔交易都由 AI 自动完成，而是大量原本因为协调成本过高而根本不会发生的交易，在经济上变得可行。**

## 三、哈耶克的知识问题：Agent 会让市场更有效率吗？

1945 年，哈耶克在《知识在社会中的运用》中指出，经济的核心难题之一是**知识分散在无数个体之中**，没有任何中央决策者能完整掌握所有人的需求、资源、偏好和局部条件。价格机制的价值在于，它能利用分散的信息协调经济活动，而不要求每个人理解整个系统。

今天这个问题有了新的技术条件。一个持续获得授权、维护长期上下文的 Agent，理论上比网站更了解用户的部分偏好：预算约束、历史选择、交付要求、时间安排。供应商的 Agent 则接入库存、产能、报价、履约规则和实时运营数据。两个 Agent 协调时交换的信息，可能比网页展示更结构化、更贴近具体交易的约束。这可能提高匹配效率。

但这不意味着市场会接近完全信息。**人类偏好不是一组固定参数。** 人们常常不知道自己真正想要什么：买车既考虑交通效率，也考虑身份认同、审美和对未来生活的想象；选大学除了学费和就业率，还在意某种难以量化的氛围。这些偏好有情境性、社会性和可变性，历史记录再丰富也未必能推断出来。

更重要的是，**偏好本身可能被系统塑造**。当 Agent 长期替你筛选信息、推荐商品、规划生活，它不只是观察你的偏好，也在改变你形成偏好的过程。所以 AME 涉及的不只是资源分配效率，还有偏好的形成机制。过去市场通过广告和品牌影响消费者；未来市场可能通过影响消费者的 Agent，间接改变消费者的选择。Agent 不是完全透明、中立的信息处理工具，它正在成为**新的经济解释者和选择架构设计者**。

## 四、一个容易被忽视的问题：Agent 到底代表谁？

这是整个 AME 最重要的制度问题。

委托代理问题不是新概念：股东委托管理者，投资者委托基金经理，消费者委托经纪人。只要委托人与代理人的目标、信息或激励不完全一致，就会有代理问题。AI Agent 把这种关系进一步扩大了。

假设你让购物 Agent 推荐笔记本电脑，它给了三个品牌。你怎么判断这些推荐真的符合你的利益？是因为性能、价格和售后最适合你，还是因为某个商家付了推荐费，或者 Agent 平台与某个品牌有商业合作，甚至只是因为某个商家的信息更容易被模型检索和调用？传统广告通常能被识别为广告；**当商业推广被嵌进 Agent 的任务规划和工具选择过程，利益冲突就更难察觉。**

理想情况下，消费者 Agent 应当在合法授权范围内，以用户效用为主要优化目标。但在商业现实中，Agent 的提供者同时追求用户满意度、平台收入、广告收益和生态扩张，这些目标未必一致。于是出现一个新问题：**当 Agent 成为主要交易中介，谁有权定义它的目标函数？**

如果用户有充分的控制权、能迁移自己的数据、能审计 Agent 的决策，Agent 更可能成为消费者利益的代理人。如果平台控制模型、用户上下文、交易入口和商业排序规则，Agent 就可能成为新的平台分发工具。这两种结构技术上看起来几乎一样，经济后果却根本不同：前者增强消费者主权，后者可能形成比搜索引擎更强的信息与交易控制力。**Agent 的能力越强，授权边界、商业利益披露和决策可解释性就越重要。**

## 五、从双边平台到多代理市场：下一代平台如何形成？

互联网时代最成功的商业组织之一是双边平台：电商连接买卖双方，网约车连接司机与乘客，支付网络连接商户与付款人。Rochet 和 Tirole 的双边市场理论系统分析了平台如何通过价格结构协调不同参与者，并利用跨边网络效应增长。

Agent 不会自动消灭这些平台，但可能改变平台组织供需的方式。传统平台要自己建界面、推荐、评价、搜索和交易系统，消费者必须进入平台才能完成这些操作。未来，用户可能先进入自己的 Agent，再由 Agent 调用不同平台的商品、服务和交易接口。**过去平台拥有用户入口，因此拥有需求分配权；未来用户 Agent 可能成为入口，商品平台退化为可调用的供给与履约网络。** 平台竞争的就不只是人的注意力，还有 Agent 的调用机会。

但不要过早断言传统平台必然衰落。拥有独占库存、真实履约能力、信用体系和交易保障的平台仍然有强大优势 —— **Agent 可以降低发现商品的成本，却无法凭空创造仓储、物流、信用与供给。** 真正可能被削弱的，是主要靠信息入口和用户迁移成本建立壁垒、却缺乏独特供给的平台。

另一方面，新的 Agent 平台也会形成自己的网络效应：用户越多，交互反馈越丰富；商家越多，可调用的服务越广；工具越丰富，能完成的任务越复杂；完成率越高，又吸引更多用户。这个循环可能让少数大型 Agent 平台成为新的经济协调中心。

2026 年 11 月 10 日，OpenAI 以 beta 形式上线 Businesses in ChatGPT：企业可以认领商家资料、维护商品数据（含价格与库存），并在通过验证后搭建 Business Agent 与潜在客户交互。首批 Business Agent 只开放给美国的电商与在线服务企业，这些 Agent 也可以作为 ChatGPT 广告的投放落点。[The Next Web](https://thenextweb.com/news/openai-businesses-in-chatgpt-business-agents) 这是早期信号，但它目前仍以发现与咨询为主，**并不意味着复杂交易已经可以自主完成**。

一个更长期的问题正在浮现：我们是否会从由少数大型网站组织的互联网，走向由少数大型 Agent 平台协调的经济？如果是，**Agent 时代就不是去中心化的胜利，而是数字中介权力的又一次集中。**

## 六、当搜索不再稀缺，可信度可能成为新的稀缺资源

1970 年，阿克洛夫在《柠檬市场》中解释了信息不对称如何导致逆向选择：买家无法辨别质量时，低质量商品会挤压高质量商品的空间。

Agent 不会让这个问题自动消失，反而可能让它以新的形式出现。当商家开始针对 Agent 优化自己的数据、描述、接口和报价，市场里会出现大量专为机器设计的商业信息，而它们未必可靠：看起来结构化、实际已经过时的库存；藏在难以比较的条款里的退款限制；甚至通过恶意内容影响 Agent，诱导它执行超出用户授权的操作。**参与者从人变成软件代理，虚假陈述、欺诈和策略操纵不仅不会消失，还获得了自动化的规模。**

所以 AME 的关键基础设施，可能不是更强的推荐系统，而是**可信的经济事实验证系统**。一笔可靠的代理交易至少要回答五个问题：

1. 商品信息是否来自可验证的真实供应商？
2. 执行交易的 Agent 是否具有有效身份？
3. 用户是否授权了这类交易、这个金额、这个期限？
4. 交易结果是否符合此前承诺的条件？
5. 执行失败、交付异常或发生欺诈时，谁承担责任？

这些不是单纯的模型推理问题，而涉及密码学、身份管理、合同制度、支付网络、风险控制、审计和司法救济。Stripe 与 Tempo 在 2026 年 3 月推出的 Machine Payments Protocol（[Stripe](https://stripe.com/blog/machine-payments-protocol)），以及 Google 联合 Shopify 等零售商推出的 Universal Commerce Protocol，可以看作机器可调用交易基础设施的早期尝试。但支付协议只解决交易过程的一部分技术问题，**不能自动解决商品质量争议、合同责任、信息真实性和平台利益冲突**。

这意味着可能出现一个有价值的商业类别：**为 Agent 经济提供可信验证与责任协调的机构**。它们未必直接服务普通消费者，而是服务 Agent 开发者、商家、支付网络和其他平台。它们出售的不是信息本身，而是**信息能被信任、行动能被验证、交易能被追责的能力**。

## 七、商业模式正在从软件使用权转向经济结果

过去十多年，SaaS 是软件行业最重要的商业模式：企业购买账号、席位和订阅，获得一套提高员工效率的工具。它的前提是，**人是软件的主要操作者，软件是人完成工作的工具**。

当 Agent 能直接执行工作流程，这个关系开始改变。一家公司每月要处理十万张发票，传统做法是买财务软件，再雇人识别、录入、审批、对账。Agent-Native 系统则可能直接接收发票，完成提取、规则校验、异常识别和录入，只把高风险事项交给人。企业关心的不再是有多少个账号，而是处理了多少有效发票、错误率多少、异常需要多少人工干预。**软件的价值衡量单位有可能从使用权转向任务结果。**

这不意味着订阅会消失。更可能的是多种模式并存：基础能力按订阅，计算与工具调用按用量，明确可验证的交付按成果，部分交易服务按成交额或实现价值。

更深远的影响是，当软件能直接完成原本需要人做的事，**软件企业与服务企业的边界会变模糊**：一家表面上卖软件的公司，实际可能在做过去外包公司、代理机构或专业服务团队的活。但结果定价也有约束 —— 成果必须能准确归因，双方必须对成功标准达成一致，异常责任必须能够划分。否则企业只是把席位定价的争议，换成了结果计量的争议。Agent 经济真正重要的创新，不只是技术成本下降，而是能否建立**新的服务合同、绩效衡量与责任分配方式**。

## 八、Agent 是否会改变企业的边界？

顺着科斯往下推，一个更有意思的问题出现了：企业为什么要雇大量员工，而不是在市场上逐项购买服务？原因之一是，在某些条件下，内部管理与长期合同比频繁的市场交易更经济。

如果 Agent 能持续搜寻供应商、协调任务、验证结果并处理结算，**使用外部市场的协调成本就会下降**。小团队也许不必建齐内部职能部门，就能获得接近大企业的部分运营能力 —— 比如一家跨境电商公司用多个 Agent 协调广告投放、采购、物流、客服和财务对账。

但不能因此断言企业会被 Agent 取代。企业存在不只是为了降低沟通成本，它还承担资产投资、组织学习、风险分担、劳动协调和长期战略决策。当工作具有高度资产专用性、复杂的隐性知识或难以验证的结果时，内部组织仍可能优于市场采购。

所以 Agent 对组织边界的影响很可能**因行业而异**：标准化程度高、任务可分解、成果易验证的行业，外部采购会增加；需要长期协作、深度专业判断、共同承担不确定性的行业，内部组织仍有优势。甚至可能出现相反情况：大企业因为有更多数据、算力和专有流程，反而比中小企业更能用好 Agent。结果取决于技术成本、组织成本和制度成本之间的相对变化，而不是 Agent 的能力单独决定 —— **这也是不能把 Agent 时代简单等同于「一人公司时代」的原因。**

## 九、谁将获得 Agent 经济创造的价值？

即使 Agent 降低了全社会的交易成本，也不意味着所有参与者平均受益。**效率提高和收益分配是两个问题。**

消费者通过 Agent 找到更便宜的商品，直接效果是消费者剩余增加。但如果 Agent 平台掌握大部分需求入口，它就能向商家收分发费；商家无法直接接触消费者，就会依赖少数 Agent 平台；提供底层模型、支付能力、真实供给和身份验证的企业，也会争夺新的价值份额。

由此至少有三种可能的市场结构：

| 结构 | 谁控制入口 | 商家如何竞争 | 主要风险 |
|---|---|---|---|
| 封闭平台主导 | 少数大型 Agent 控制用户上下文、工具接入与交易入口 | 按平台规则竞争分发 | 用户便利，但平台依赖度高 |
| 开放协议竞争 | 用户可在不同 Agent 间迁移授权、偏好与部分任务状态 | 通过标准接口服务多个 Agent | 互操作减轻锁定，但标准仍可能由少数大玩家主导 |
| 混合结构 | 通用 Agent 控制主要交互入口，专业 Agent 负责垂直领域复杂任务 | 开放协议连接部分基础设施 | 集中与开放并存，边界随行业变化 |

考虑到现有平台的分发优势，以及金融、医疗、物流等行业特殊的合规与履约要求，我认为**混合结构是最值得重点研究的中期情景**。这只是条件性判断，不是必然的技术路线。

最值得注意的是，**Agent 的效率优势和平台的市场集中度可能同时提高**。如果一个 Agent 平台降低了用户的搜索成本，又通过商业排序收取更高的中介费，部分效率收益就会转移给平台，而不是消费者。因此评价 Agent 经济不能只看任务完成率或交易规模，还要看消费者剩余、供应商利润、市场进入壁垒、平台抽成比例和数据迁移能力。**值得追求的不是市场里有更多 Agent，而是有了更多 Agent 之后，市场仍然保持有效竞争。**

## 十、从经济学延伸到社会学：当选择本身开始被外包

经济学关心资源如何有效配置，但人的生活不只是资源配置。消费也是社会行为：人们通过购物表达身份，通过旅行探索世界，通过选择餐厅建立关系，通过亲自研究与比较形成知识。这些行为有些看起来并不高效，却有社会和文化意义。

假设你的 Agent 能替你完成几乎所有日常消费决策，知道你的预算、熟悉你的口味、总能找到性价比更高的东西。从效率看这是进步。但如果你几乎不再浏览商品、不再偶然发现新品牌、不再和陌生商家交流，你接触世界的方式也变了。传统互联网通过搜索和推荐决定你能看到什么；**Agent 则进一步决定哪些选项值得被你看到，以及哪些事根本不需要你亲自处理**。这是一种更深层的选择中介化。

它可能降低日常生活的认知负担，让人把时间投入创造、学习和人际关系；也可能让人越来越依赖少数系统替自己理解市场、组织生活。更值得警惕的是，当 Agent 长期按历史偏好优化，它倾向于重复你已经表现出的选择，而不是鼓励探索。如果一个人的消费、阅读、旅行和学习都由同一个优化系统协调，生活中的意外发现会不会减少？

这不是推荐准确率能回答的问题。**人的价值并不完全来自目标的实现；探索、试错、犹豫、改变主意，本身就是偏好形成和人格发展的过程。** 优质的 Agent 未必应该替人做出所有决定，它还应该知道哪些决定值得留给人，什么时候该提出不同意见，什么时候该主动让用户接触新信息。Agent 的成功标准不只是减少操作次数，还包括**它是在扩展人的自主性，还是在逐渐替代它**。

## 十一、2026 年的现实：我们距离这种经济还有多远？

回到现实。截至 2026 年 11 月，AME 仍在早期。

公开可查的 Agent 流量数据结构很一致。HUMAN Security 统计 2025 全年，Agent 与 Agent 浏览器的流量同比增长 7,851%，但 **77% 落在商品与搜索页，只有 2.3% 落在结账页**（[HUMAN](https://www.humansecurity.com/learn/resources/2026-state-of-ai-traffic-cyberthreat-benchmarks/)）；2026 年 4 月的月报里，结账与支付占 Agent 流量的 3.16%（[HUMAN](https://www.humansecurity.com/learn/blog/state-of-agentic-traffic-april-26/)）。这些是单一安全厂商的监测样本，不代表整个互联网；到达支付端点也不等于完成购买。但它们足以支持一个谨慎的判断：**Agent 已经开始改变信息发现，自主交易的成熟度明显落后于信息检索。**

这和技术演进的逻辑一致。搜索失败通常只损失时间，推荐错误造成选择偏差，**交易执行错误则直接造成经济损失**。任务从信息处理走向真实世界的行动，系统要承担的风险和责任会快速上升。

所以未来几年判断 Agent 经济是否成熟，不该只看 Agent 流量、Token 消耗和模型排名，而要看这几件事：

- Agent 能否在明确授权范围内**稳定完成真实交易**？
- 交易失败后，能否恢复或给出有效补偿？
- 不同平台的 Agent 能否互操作？
- 消费者能否控制和迁移自己的代理身份与偏好？
- 商家能否获得公平的竞争机会？
- Agent 创造的效率收益，最终是否转化为**更低的价格、更好的服务和更广泛的市场参与**？

这些问题能帮我们区分技术演示、商业增长和真正的制度变迁。

## 十二、真正的机会，不是建立更多 Agent，而是重建 Agent 可以参与的市场

对创业者来说，最容易误判的地方，是把 Agent 经济理解成一个新的软件品类 —— 直觉上就去做购物 Agent、旅行 Agent、金融 Agent、招聘 Agent。这些当然可能有价值，但从产业结构看，另一类机会可能更持久：**当越来越多的软件代理参与真实经济活动，市场需要一套让它们安全协作的基础设施。**

供应商要提供真实、及时、可验证的商品与服务信息；用户要能设置授权范围、预算上限和风险偏好；系统要保证执行的幂等性、一致性和可恢复性；支付机构要分辨合法的机器交易和欺诈；交易双方要记录承诺、核验履约，并在争议时确定责任。这些需求不会因为基础模型变强而消失。模型能力提高可以降低推理成本和部分操作错误，**但不能取代真实世界里的产权制度、合同关系和责任承担**。

从第一性原理出发，我认为 Agent 经济里最有价值的企业会在三个层面竞争：

| 层面 | 要回答的问题 | 可能的壁垒 |
|---|---|---|
| 需求协调 | 谁能准确理解用户目标，并在多个供应商之间建立可靠的选择机制？ | 强网络效应 |
| 可信供给 | 谁能提供真实、稀缺、难以替代、可被程序验证的商品、数据和服务？ | 专业领域壁垒 |
| 交易保障 | 谁能在多步骤、有不确定性的环境中，保证授权有效、执行可靠、结果可核验、风险可控？ | 生态反复调用的基础能力 |

三个层面之间既竞争也协作。对创业者，真正要回答的不是「我能不能做一个 Agent」，而是：**当一个越来越聪明的 Agent 试图完成某项真实经济活动时，还有什么是它不能仅靠推理能力解决的？** 答案所在的位置，往往就是值得研究的机会。

## 结语：下一代互联网，可能是一套经济协调系统

重要的技术革命往往不只改变人们用什么工具，还改变社会组织经济活动的方式。互联网让信息跨越地理边界，移动互联网让交易入口随时可用，云计算降低了获取算力的成本；**Agent 可能进一步降低把人类意图转化为跨系统行动的协调成本。**

但 AME 不意味着机器成为经济的最终目的，也不意味着消费者、企业和传统市场被自动化系统取代。人仍然定义需求、承担责任、享受商品与服务带来的效用。变化的是人参与经济活动的方式：过去我们亲自进入市场寻找、比较、协商、成交；未来我们越来越多地通过自己的数字代理参与市场。商业竞争会从争夺人的注意力，扩展到争夺代理系统的选择与调用。

它也重新提出了几个古老的问题：**谁掌握信息？谁拥有决策权？谁控制交易入口？谁承担风险？谁获得增长创造的价值？** 从科斯、哈耶克到现代平台经济学一直在讨论的这些问题，不会因为 AI 的出现而消失；当越来越多的决策交给软件，它们只会更重要。

B2A 描述的是企业如何面对一种新的软件用户；AME 讨论的是，当这些软件用户开始替人协调经济活动时，市场本身会发生什么。前者是商业模式的延伸，后者可能是经济组织方式的演变。下一代互联网未必是一个更庞大的内容网络，它可能逐渐变成一套**由人设定目标、由 Agent 协调任务、由企业提供真实供给、由可信制度保障交易**的经济协作系统。

它会带来更开放的市场，还是新的平台垄断，目前没有答案。技术可以降低协调成本，却无法自动决定效率收益归谁。所以真正要关注的，不只是 Agent 能替人完成多少事，而是**当越来越多的决定不再由人亲自执行时，我们能否建立一种新的经济秩序，让技术提高效率的同时，仍然保留市场竞争、个人自主与可追责的制度结构**。

下一次互联网革命，也许不是让每个人拥有一个更聪明的助手，而是让整个市场学会如何与这些助手共同运转。决定它最终意义的，不是机器能交易多少次，而是人是否真正从中获得了更大的自由与更多的选择。
