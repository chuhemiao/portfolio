## TL;DR

a16z の中心的な判断は**おおむね妥当だが、あらゆるリスクが取引資産になるという主張には、観測可能、価格形成可能、決済可能、継続的な双方向の資本需要という四条件が必要だ**。

ブロックチェーンが変えるのは既存取引の移転ではなく、市場の供給過程を分解することだ。**誰でもリスクの単位を定義し、取引の仕組みを展開し、世界の流動性へ接続し、オラクルと担保で決済できる**。Hyperliquid の HIP-3、HIP-4、RWA 無期限先物、予測市場は、その初期の実例である。

ただし供給が許可不要でも、品質を作らなくてよいわけではない。今後価値が大きいのは、単なるトークン発行とは限らず、

- オラクルと決済。
- 初期流動性とマーケットメイク。
- 証拠金、清算、テールリスク管理。
- 市場の発見と世界への販売。
- 法令上の境界とデータ標準化。

**私の結論は、a16z は次の大きな方向を捉えているが、より正確には、標準化され、オラクルで表現でき、資本が引き受けるリスクは独自の市場を持ちうる、ということだ**。

## 中心的な判断：変わるのは市場の供給関数

a16z 原文は二つの軸に分ける。

1. **リスクの単位**：企業のキャッシュフロー、石油、選挙結果、借り手の信用、GPU 時間。
2. **リスク移転の道具**：現物、先物、無期限先物、オプション、イベント契約。

従来の革新は一度に一軸を変えることが多かった。穀物の現物の後に先物、株式の後にオプションと ETF が生まれた。金利、信用不履行、ボラティリティ、イベント結果も、長い時間を経て標準化された道具を得た。

重要な洞察は、**過去の金融市場の障害は、需要より供給であることが多かった**という点だ。

従来の供給は三種類の要因で制限される。

| 従来の障害 | ブロックチェーンの改善 | 残る問題 |
|---|---|---|
| 上場委員会と法的承認 | 開かれた権限、プログラム可能な発行 | 法令対応と責任は消えない |
| 地理・取引時間 | 世界のウォレット、7×24 時間取引 | 流動性は断片化しうる |
| 中央清算と証拠金の分離 | 統一証拠金、オンチェーン清算 | 市場間伝播と清算リスクが増す |
| 初期マーケットメイクの不足 | AMM、報酬、共有注文板 | 報酬終了後も本当の流動性が残るか |
| 私募・非標準リスクの価格形成 | 合成契約、予測市場 | オラクル・決済標準が不確かもしれない |

真の製品は速い取引だけでなく、新しい**市場生産システム**だ。

> リスク定義 → オラクル → 担保 → 初期流動性 → リスク管理と決済 → 世界への販売

一つでも失敗すれば、トークンや契約はあっても、利用できる市場がない状態になる。

添付資料が触れる翻訳も訂正すべきだ。原文は **memory stocks**、つまりメモリー／記憶装置向け半導体株であり、ミーム株を指す **meme stocks** ではない。文化的な注目資産だけでなく、半導体サイクルとメモリーチップのリスクの市場化を観察していたという重要な違いがある。[a16z 原文](https://a16zcrypto.com/posts/article/blockchains-create-net-new-markets/)

## 実例：無期限先物は非暗号資産リスクをオンチェーン化した

### 1. RWA 無期限先物は構想から規模の段階へ

CoinGecko の *RWA Report 2026* は、

- **2026 年第一四半期の取引高は $524.79B**。
- **2025 年通年の $313.02B** を上回る。
- 2026 年第一四半期の日平均未決済建玉は約 **$4.82B**。
- Hyperliquid HIP-3 は 2026 年 3 月の月間 RWA 無期限先物取引高の約 **28.6%**。
- HIP-3 の 2026 年第一四半期の累積取引高は約 **$130.87B**。[CoinGecko RWA Report 2026](https://www.coingecko.com/research/publications/rwa-report-2026)

単なる株式トークン化ではなく、より正確には、

> 既存のリスク対象 × より開かれ、連続的で、レバレッジのある移転手段

だ。株式、指数、原油、金、為替、上場前企業には元からリスクがあるが、アクセスは時間、地域、資格、決済、証拠金分離で制限される。無期限先物はそれを次へ集約する。

- 受け入れられる価格源。
- 証拠金・清算のルール。
- 十分なロングとショートのトレーダー。
- 市場運営の責任を負うデプロイヤー。

a16z の **7 月の RWA 無期限先物取引高は年率 $1.4T のランレートで、Hyperliquid の帳簿の約半分**という数字は、稼働ペースの換算だ。CoinGecko の $524.79B は四半期累積である。期間と範囲が違い、足したり単純比較したりできない。前者は成長の速度、後者は実際の規模を示すのに向く。

### 2. HIP-3 は上場自体の製品化を示す

HIP-3 は誰でも無料で上場できる仕組みではなく、builder に市場展開の責任を渡す。

- メインネットのデプロイヤーは **500,000 HYPE** をステークする。
- ステーク要件は最低 **183 日**維持する。
- 市場定義、オラクル、レバレッジ設定、運営に責任を持つ。
- 検証者は、悪意ある行為やプロトコルの安全性を損なう行為に対して罰則を科すことができる。
- 各 HIP-3 DEX は独立の注文板、証拠金、デプロイヤー設定を持つ。
- クロスマージン市場は流動性、オラクル、操作耐性の条件も満たす。[Hyperliquid HIP-3 公式仕様](https://hyperliquid.gitbook.io/hyperliquid-docs/hyperliquid-improvement-proposals-hips/hip-3-builder-deployed-perpetuals)

革新は許可不要という言葉だけでなく、従来取引所内の一体的な機能を分けることだ。

- プロトコルがマッチング、清算、証拠金、決済を提供する。
- Builder が対象、ルール、オラクルを定義する。
- マーケットメーカーが初期の厚みを提供する。
- フロントエンドがユーザーを獲得する。
- データ提供者が市場を見えるようにする。

これは**金融市場インフラのモジュール化**である。

### 3. 上場前の無期限先物が価格発見への参加を示す

Talos の Cerebras と SpaceX の上場前先物調査は具体例を示す。

- Cerebras は一時、Nasdaq の寄り付き **$350 の 1.3% 以内**だった。
- 実際の株式、IPO 割当、所有権、議決権は表さない。
- SpaceX は該当段階で **$215M 超の未決済建玉**と約 **$2.2B の累積取引高**を持った。
- Cerebras 上場後の外部株価との乖離は、中央値で約 **0.07%** へさらに縮小した。[Talos / Coin Metrics](https://www.talos.com/insights/state-of-the-network-367)

**連続的な評価シグナル**になりうるが、実株市場とは同じでない。価格が表すのは、

- IPO 価格への期待。
- 私募の二次市場評価。
- 投機資金の混み具合。
- 取引所内部の合成価格。

かもしれない。価格発見には実例の裏付けがあるが、**特定の注目銘柄での補助的な価格発見**に近く、銀行、引受会社、主要証券取引所の全面代替を証明しない。

## 市場の基本要素はイベント、確率、新リスク単位へ広がる

a16z の強みは、すべてを RWA に還元せず、二種類の拡張を描く点だ。

### A. 既存リスクの新しい移転方法

| リスク対象 | 新しい道具 | 主な価値 |
|---|---|---|
| 株式、指数 | 7×24 時間無期限先物 | 時間帯を越えた取引、統一証拠金、時間外の価格発見 |
| 石油、金、金属 | RWA 無期限先物 | 地域・口座の障壁を下げる |
| 非公開企業の株式 | 上場前無期限先物 | 事前の連続評価 |
| 為替、マクロ指標 | 無期限先物・イベント契約 | 時間とレバレッジによる表現の拡張 |
| 債務、信用 | 個人対プール貸付、信用市場 | 非標準の信用を連続価格へ |

### B. 新しいリスク単位自体の金融表現

| 新しいリスク単位 | 市場形態 | 重要な難点 |
|---|---|---|
| CPI、金利決定、裁判所の判断 | 予測市場、イベント契約 | 出典、決済時刻、定義 |
| スポーツ、選挙 | Yes/No・複数結果 | 結果の争い、規制、流動性 |
| GPU 時間、計算能力 | 計算力先物、容量契約 | 引渡し標準、品質差、物理制約 |
| 音楽、社会的トレンド | 注目・文化資産 | 指標が操作されやすい |
| NFT、ミームコイン | 文化的関連性・注目の市場 | ノイズ、短期操作、寿命 |
| 個人の信用 | 個人対プール貸付、信用持ち分 | 本人確認、不履行、法的請求 |

HIP-4 は無期限先物が終点でないことを示す。outcome markets は**全額担保、固定範囲、期限付きの契約**で、二値・複数結果に対応し、レバレッジに依存せず、従来の強制清算もない。公式の最初の市場は BTC 価格に基づく周期的な二値結果契約だ。[Hyperliquid HIP-4 公式仕様](https://hyperliquid.gitbook.io/hyperliquid-docs/hyperliquid-improvement-proposals-hips/hip-4-outcome-markets)

確率市場に近く、

- Yes の価格を暗黙の確率と読める。
- No は反対の結果。
- 両方向が注文板の流動性を共有する。
- 終了後に結果で決済する。

予測市場の需要も小規模な現象ではない。2026 年 4 月に Galaxy は Polymarket と Kalshi の月間想定元本取引高を約 **$24B**、累積を **$150B 超**と集計した。2026 年 10 月 22 日前後の集計スナップショットでは直近 30 日の日次合計は約 **$81.6B**、Kalshi は約 **$79.7B**、Polymarket は約 **$1.9B**。カバー日数と想定元本の基準が同一ではなく、活動度の判断に限り、RWA 無期限先物と直接比較できない。[Galaxy Research：The Race to Trade Everything](https://www.galaxy.com/insights/research/hyperliquid-hip-4-prediction-markets-polymarket-kalshi-analysis)

重要な境界は、**HIP-4 の基本要素が公開済みでも、任意のイベント市場が全面開放済みとは限らない**ことだ。公式は段階展開を強調し、2026 年 7–9 月の報道も主にテストネット、テンプレート、今後の更新経路を扱っていた。[The Block の HIP-4 permissionless deployment 報道](https://www.theblock.co/post/408875/hyperliquid-hip-4-permissionless-deployment) 許可不要の供給は段階的な開放中で、HIP-3 の builder-perp と完全に同一ではない。

## 成り立つ部分と、過度な外挿

### 1. 二人のトレーダーと一つのオラクルだけでは足りない

頑健なオラクルと二人の相手で上市できるという説明は簡潔だが、実際には、

- 初期注文板の厚み。
- マーケットメーカーの在庫・テールリスク負担。
- 適切なレバレッジと証拠金。
- 清算と不良債権処理。
- 操作防止。
- 信頼できる停止と決済。
- ユーザー獲得と継続動機。

も必要だ。なければ技術上は存在しても大口取引を扱えない。

### 2. 許可不要は上場フィルターと品質フィルターをともに外す

大量のノイズが生まれることを a16z も認める。しかし自然淘汰で常に良い市場が残るとは限らない。

- 初期報酬が偽の取引量を作りうる。
- 薄い市場は少数に操作されやすい。
- 価格はオラクルや内部注文板の反映だけかもしれない。
- 最も有用でなく、宣伝が最もうまい市場が勝つかもしれない。
- クロスマージンが低品質市場のリスクをほかへ移す。

HIP-3 の 500,000 HYPE の担保、検証者による罰則、クロスマージン資格、オンチェーン backstop liquidator は、**自由発行に経済的担保、統治、清算の後備が必要だ**と運営側も認める証拠だ。

### 3. 24×7 取引は世界中での合法的利用とは違う

技術的な世界展開と法的な世界からのアクセスは同じでない。

株式・商品先物には、

- 原資産の実際の受渡し権がない。
- 株主権がない。
- 地域制限がある。
- デリバティブ・証券規制の対象。
- 中央集権的なデータ源への依存。
- 発行者、取引基盤、オラクルの多重の相手方リスク。

がありうる。強みは**リスクへのエクスポージャーを得られること**で、原資産の権利の自動取得ではない。

### 4. 取引高は需要の質ではない

取引高は、

- 高頻度マーケットメイク。
- 資金調達率の裁定。
- 基盤間のベーシス取引。
- レバレッジ循環。
- エアドロップ・手数料報酬。
- 短期イベント。

からも生まれる。より信頼できる指標は次だ。

| 指標 | 観察点 |
|---|---|
| 未決済建玉 | 出来高以外に継続的なリスク引受けがあるか |
| 出来高 / 未決済建玉 | 長期配分か高頻度回転か |
| 報酬終了後の取引高 | 実需要があるか |
| スプレッドと市場影響 | 大口を執行できるか |
| オラクルの価格差 | 安定し、操作に強いか |
| イベント決済精度 | 規則に従い終結できるか |
| メーカー数 | 単一提供者への依存があるか |
| 基盤間の価格差 | 裁定できる合意価格があるか |

新市場を速く作れる実例はあるが、報酬後も生存できるかには長い期間のデータが必要だ。

## 価値獲得と今後 12–24 か月

### 誰が価値を得る可能性が高いか

重要な投資上の意味は、次がどの資産かではなく、**誰が市場供給網を握るか**だ。

優先順位はおおむね、

1. **展開層**：仕様、オラクル、取引時間、決済規則。
2. **取引・清算場所**：注文板、証拠金、清算、市場横断の組合せ。
3. **オラクル・データ層**：検証可能、低遅延、操作耐性のあるデータ。
4. **流動性立ち上げ層**：初期メイク、引受け、報酬設計。
5. **販売・フロントエンド層**：世界のユーザー、機関、ボットへ届ける。
6. **担保・信用層**：ステーブルコイン、収益資産、貸付、ポートフォリオ証拠金。

よくある誤解だが、**プロトコルに取引量があっても、トークンが必ず価値を得るわけではない**。取引高が次へ転換するかを確認する必要がある。

- 持続的な手数料。
- デプロイヤー収入。
- ステーク需要。
- 買い戻し・バーン。
- 清算・決済収入。
- 担保の構造的な需要。

### 三つのシナリオ

| シナリオ | 展開 | 主な検証シグナル |
|---|---|---|
| 基本 | RWA 先物とイベントは伸びるが、少数の大手に流動性集中 | 少数市場が高 OI を維持し、報酬縮小後も安定 |
| 楽観 | 時間外・非標準資産の主な価格発見層になる | 機関メイク、裁定、実ヘッジ、主要市場との連動が増す |
| 悲観 | 多数が補助依存、オラクル・清算事故で信頼危機 | 出来高・OI が落ち、価格差と規制が強まる |

新市場の数より、五つの問いが重要だ。

1. **90 日後も流動性を保てるか**。
2. **取引高は報酬や水増しでなく、実際のリスク移転で生じるか**。
3. **オラクルと決済が新しい障害になるか**。
4. **暗号資産の投機家だけでなくヘッジ需要を集められるか**。
5. **成長を持続的なキャッシュフローとトークン需要へ変えられるか**。

## 結論

主張はすべてをトークンにするということではなく、さらに深い命題だ。

> 市場を、取引所、規制当局、仲介者が集中的に作る商品から、開発者、データ提供者、マーケットメーカー、プロトコルが共同生産する開かれたインフラへ変えつつある。

無期限先物は、オラクルで記述するリスクに証拠金、注文板、双方向の参加者があれば、世界的・連続的・組合せ可能な市場になる、という最小形へ圧縮するため重要だ。

あらゆるリスクを取引できるという表現は、次に置き換えるべきだ。

> **標準化、継続観測、確実な決済ができ、十分な双方向資本が引き受けるリスクは、それぞれの市場を持ちうる**。

**最終判断**。トレーダーは新対象だけでなく、オラクル品質、流動性、清算、決済を見る。起業家や投資家が築く価値は単なる発行でなく、市場品質のインフラにある。公開後も信頼でき、取引でき、持続する市場を作れる主体ほど、この供給側革命の価値を得やすい。
