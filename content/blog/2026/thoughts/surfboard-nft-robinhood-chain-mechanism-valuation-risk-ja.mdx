## TL;DR

SurfBoard は従来のプロフィール画像型 NFT ではなく、**NFT の希少性、二次取引の手数料、Robinhood Chain 上の米国株／ETF のトークン化資産**を組み合わせた収益型のデジタル資産だ。中心的な仕組みは、**未開封の SurfBoard は取引できるだけで株式収益を生まない。開封すると希少性が明らかになり、一つの株式トラックへ割り当てられ、取引手数料で購入した株式トークンを受け取り始める**というものだ。

**2026-10-16 05:29 UTC** のサイトのスナップショットは次のとおり。

- 総供給量：**6,666 個**
- 封印済み：**4,251 個**
- 開封済み：**2,415 個、約 36.2%**
- 封印プールの提示価格：約 **$195.65**
- 封印プールの厚み：**19.956 ETH**
- 取引手数料：**3%**
- マーケットページの掲載数は約 **317 個**、24 時間取引量は約 **$56,581**
- 公式サイトの推定 APR は約 **77.1%–977.4%**。ただし過去 7 日間の手数料を年率換算した推定であり、固定利率でも保証された収益でもない。

私の中心的な判断は、**無料で受領できる適格ユーザーには参加する価値が比較的高い。一方、約 $195 で購入してすぐ開封するユーザーにとって、APR だけを理由に高値を追える明確な投資機会ではない**というものだ。公式サイトは開封後の推定価値を約 **$157.82** と示し、封印プールの価格より約 **19.3%** 低い。高い APR は、取引量、開封数、株式トークンの流動性、償還の仕組みが持続できるかに大きく依存する。

### 封印と開封

各 SurfBoard には二つの状態がある。

1. **Sealed、封印状態**
   - 保有または取引できる。
   - 株式収益は生まない。
   - 開封前には、希少性をランダムに明かす可能性が残る。
   - 現在のサイトでは、開封に完全な **1.0 SurfBoard** の保有を求めている。

2. **Opened、開封状態**
   - 希少性とアートの属性を明らかにする。
   - 五つの株式トラックの一つへ割り当てられる。
   - ウェイトに応じ、対応トラックの手数料収益を分け合い始める。
   - 引き続き取引でき、蓄積した株式資産は NFT とともに新しい保有者へ移る。
   - 償還によって NFT をバーンできる。公式ルールでは保有者が累積資産の **95%** を受け取り、残り **5%** はほかの開封済み SurfBoard に分配される。

したがって SurfBoard の価値は、画像の希少性だけではなく、次のように表せる。

> SurfBoard の価値 = 希少性 + 将来の手数料分配 + 累積株式トークン価値 + 流動性プレミアムまたはディスカウント

ただし四つの要素はどれも固定されていない。公式サイトも、APR は取引量や同じトラックのボード数によって急速に変わると明示する。[SurfBoard ホームページ](https://nft.asksurf.ai/)

## 収益モデルと株式資産の流れ

### 手数料から株式資産への変換

取引ページは次を示す。

- 封印 SurfBoard は統一された流動性プールで取引する。
- 取引手数料は **3%**。
- 手数料で株式トークンを購入する。
- 各ラウンドで資金を五つの株式トラックへ割り当てる。
- 各トラックは、そのトラックの開封済み SurfBoard にのみ収益を分配する。

公式の最新台帳では、2026-10-16 の第 124、125 ラウンドの各収入が約 **$48.89** とされ、五つの資産の購入数量が記録されている。[SurfBoard Ledger](https://nft.asksurf.ai/rules/ledger)

オンチェーンにも対応する実行記録がある。トランザクション `0x45e3172434fb33ef9a7aceb9f8eb1d75c1e6942c10550885ad6996dc9317a27e` は **2026-10-16 04:46:48 UTC** に `runEpoch` を正常実行した。Blockscout には約 **0.02 WETH、$48.92 相当**の流入が表示され、$SPY、$NVDA などの Robinhood Stock Token のオンチェーン移転もある。[Blockscout の取引記録](https://robinhoodchain.blockscout.com/tx/0x45e3172434fb33ef9a7aceb9f8eb1d75c1e6942c10550885ad6996dc9317a27e)

つまり、手数料から株式トークンへの変換はフロントエンドの表示だけではなく、少なくとも実際のオンチェーン epoch 実行記録がある。ただし、それは次を意味しない。

- 将来のすべてのラウンドが成功する。
- 各ボードが安定して同じ収益を得る。
- 表示された金額で必ず償還できる。
- 株式トークンの価格や流動性が変わらない。

### APR の本質

ルールページの APR 計算式は次のとおり。

> APR =（過去 7 日間の当該等級の手数料収益 ÷ 当該等級の市場価格）× 52

従来の貸付プロトコルの固定利率でも、株式ポートフォリオの予想年率リターンでもない。むしろ、

> 手数料の流入速度 ÷ 現在のボード価格

に近い。したがって APR は次の影響を受ける。

1. SurfBoard の取引量の増減。
2. 開封済みボードの増加。
3. 特定の株式トラックのボード数。
4. ボードの市場価格の変化。
5. 償還、バーン、再開封の動き。
6. 裏付けとなる株式トークンの価格変化。

たとえば取引量が変わらず、同じトラックのボード数が増えると、一枚あたりの手数料収益は減る可能性がある。取引量が急増すれば APR も急速に上がりうる。現在のページの **900% 前後の APR は、持続可能なキャッシュフローの約束よりも、過去 7 日間の取引活動を年率換算したスナップショットに近い**。

### 五つのトラックで収益が完全に同じにはならない

Board ページでは、個々の NFT が一つの株式トラックと結びつく。たとえば現在の SurfBoard #829 は次のように表示される。

- Common
- GOOGL トラック
- ウェイト ×1
- 累積株式資産は約 $5.62

したがって、すべてのボードを同じ利回りの資産として扱えない。トラックごとに取引の活発さ、ボード数、株式価格が違う可能性がある。[SurfBoard #829](https://nft.asksurf.ai/board/829)

### Robinhood Stock Token の法的性質

Robinhood の公式文書は、Stock Tokens を Robinhood Assets (Jersey) Limited が発行する**トークン化された債務証券**と説明する。株式や ETF への経済的エクスポージャーを提供するが、裏付け株式の法的所有権や受益所有権を保有者に与えない。また、米国人に対する制限を含む地域制限も記載している。[Robinhood Stock Tokens の公式文書](https://docs.robinhood.com/chain/stock-tokens)

SurfBoard にとって、これは従来の証券会社の口座で株式を直接保有するものではないことを意味する。収益の流れは次に依存する。

- Robinhood Stock Token の発行と償還の仕組み。
- Robinhood Chain の流動性。
- 発行者とその法的条件。
- 適用地域とユーザー資格。
- Surf コントラクトがこれらのトークンを保有、評価、分配する方法。

SurfBoard の米国株収益は、**オンチェーンの株式トークンの仕組みを通じた経済的エクスポージャー**と理解すべきで、NFT 保有者が $SPY、$NVDA、META の株式を直接所有することと同一視してはいけない。

## 評価：無料受領は高値での購入より有利

### 購入して開封する時点の採算は優位ではない

ホームページは現在、次を同時に表示する。

- 封印 SurfBoard の価格：約 **$195.67**。
- 開封後の推定価値：約 **$157.82**。

取引ページの約 $195.65 を使うと、公式の推定値は次の割合だけ低い。

> 推定値のディスカウント = 1 −（157.82 ÷ 195.65）≈ 19.3%

これは開封後に必ず損失になるという意味ではない。理由は次のとおり。

- 開封後も将来の手数料分配を継続して得る。
- 希少性に二次市場のプレミアムが付く可能性がある。
- 株式トークンの価格が上昇する可能性がある。
- 公式の開封後の推定価値は、将来のキャッシュフローの完全な割引評価ではなく、主に現在の即時的な価値を示している可能性がある。

ただし少なくとも、**現在の封印 NFT を購入してすぐ開封する取引は、提示価格の面だけで明らかに期待値が正とはいえない**。

### APR だけで $195 の価格を支えられない理由

ある Common が 900% APR と表示されても、毎年元本の 9 倍を得られるとはいえない。理由は、

- APR は過去 7 日間の手数料の年率換算。
- 取引量は短期イベントで増えている可能性がある。
- 新しい開封は分母を増やす。
- 償還は稼働中のボード数を減らすが、分配構造も変える。
- 収益は株式トークンとして蓄積され、ステーブルコインとは限らない。
- 株式トークン自体の価格が上下する。
- 償還は 95% にとどまる。
- 売買スプレッドと 3% の手数料が実際のリターンへ大きく影響する。

より妥当な評価の枠組みは次のとおり。

> 実際のリターン = 株式トークンの価格変化 + 手数料分配 − 取引手数料 − スリッページ − 償還ディスカウント − 流動性ディスカウント

### 参加方法による魅力の違い

| 参加方法 | 分析上の判断 |
|---|---|
| 適格ユーザーの無料受領 | 相対的に最も魅力があり、取得原価が低い。ただしコントラクト、流動性、償還のリスクはある |
| 封印 NFT を購入して抽選 | リスクが高い。通常開封は Common の確率が高く、現在の推定値は封印の提示価格より低い |
| 開封済み Common の購入 | 購入価格、累積株式資産、トラック、実際の APR を比べる必要があり、フロア価格だけでは判断できない |
| Legendary/Mythic の購入 | 希少性プレミアムは大きくなりうるが、流動性はより弱く、少数の取引で価格が動きやすい |
| 高い APR だけを追う | 推奨しない。APR は取引量と開封数に非常に敏感 |
| アートの収集だけを目的に購入 | NFT のアートとコミュニティの価値で評価し、株式収益を確実なリターンとみなさない |

### 受領資格にも版による違いがある

現在の受領ページは次を示す。

- Pro または Max の会員番号ごとに無料の SurfBoard を一つ受け取れる。
- Max の番号には Max Ticket が付く。
- 受領期限は 2026-11-13。

しかし以前の公式 X スレッドでは、2026-09-16 より前に年会員を購入したユーザーが、期限切れの一部ユーザーも含め、対応する NFT ticket を持つと説明されていた。それ以前に更新したユーザーは二枚目を得られる可能性がある。[SurfBoard Claim](https://nft.asksurf.ai/claim)

したがって、Pro/Max ユーザーであるだけで必ず資格があるとは推論できない。最も確実な確認方法は、

1. 公式 NFT ページからウォレットを接続する。
2. 実際に表示される reserved board や ticket を確認する。
3. Max/Pro の資格と期限を照合する。
4. 非公式リンクから無制限の承認に署名しない。

## リスク、材料、監視の枠組み

### 主なリスク

| リスク | 水準 | 影響 |
|---|---|---|
| 取引量への依存 | 高 | 取引減少は手数料収益と APR を直接下げる |
| 流動性リスク | 高 | 現在のプールは限られ、大口取引で大きなスリッページが生じうる |
| コントラクトリスク | 高 | 検証済みは監査済みを意味しない。特有のプロキシ構造のアップグレード権限も調べる必要がある |
| 株式トークンの発行者リスク | 高 | 収益は Robinhood Stock Token の発行、流動性、地域ルールに依存する |
| 償還実行リスク | 中高 | 95% はプロトコルのルールだが、コントラクト残高と実行状況の継続確認が必要 |
| 希少性の確率リスク | 中高 | 通常開封は Common の確率が高く、一般ユーザーの Mythic 獲得確率はゼロに近い |
| 市場価格の不整合 | 中高 | 封印プール価格、開封済みのフロア価格、累積資産価格は同じ基準ではない |
| ドキュメントの版の違い | 中 | 公式 X と現在の Rules で供給の名称と分布が異なる |
| 運営上の集中 | 中高 | 封印トークンは主に準備用、プール、少数のアドレスに集中 |
| 法域と資格の制限 | 高 | Robinhood Stock Tokens には米国人やほかの地域への制限があり、現地の適法性を確認する必要がある |

### プラスの材料

SurfBoard のプラス材料は、従来の NFT のアートへの投機というより、利用量に基づく。

1. Surf のユーザーと取引活動が継続して増える。
2. 取引手数料の収入が高い水準を保つ。
3. 開封済みボードの増加が取引量の増加より遅い。
4. Robinhood Chain の株式トークンが取引可能・償還可能な状態を保つ。
5. Surf が NFT と購読特典、会員制度、AI 製品をさらに結びつける。
6. 公式が公開監査、コントラクト権限、資金の流れ、償還準備金の証拠を補う。

### 継続して見るべき指標

APR だけでなく、毎週次を見ることを勧める。

- 24 時間取引量と 7 日平均取引量。
- 流動性プールの厚み。
- 購入価格と売却価格のスプレッド。
- 24 時間の株式資産への流入額。
- 最新の ledger ラウンドが継続して成功しているか。
- 各トラックの開封済みボード数。
- 一枚あたりの実際の累積株式資産。
- 95% 償還の実際の実行状況。
