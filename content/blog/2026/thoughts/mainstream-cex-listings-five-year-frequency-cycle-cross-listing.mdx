## TL;DR

过去 5 年，主流 CEX 上币已经从“单一交易所公告”变成了**多交易所级联**：Bybit 最像早期发现层，Binance 的交易对 / 产品事件最多，OKX 在 2025-2026 明显提速，Coinbase 和 Upbit 更偏选择性确认。

核心数据：2021-08-10 至 2026-08-10，五家交易所合计出现 **5,591 条上币事件**，折算为 **2,372 次 token-交易所首次上新**，覆盖 **1,323 个去重 token 符号**；其中 **558 个符号**被至少两家交易所交叉上新，**192 个**在 30 天内完成多交易所级联。交易上，最值得盯的是 **Bybit / OKX / Binance 的 7-30 天联动**，Coinbase / Upbit 更适合作为二次确认信号。

## 数据口径

本文覆盖你点名的五家：**Coinbase、Binance、OKX、Bybit、Upbit**。数据源为 Surf Exchange Listing Events，按 `effective_at` 统计，数据截止 **2026-08-10 02:40 UTC**；分析窗口为 **2021-08-10 至 2026-08-10**。

| 口径 | 定义 | 为什么重要 |
|---|---|---|
| 上币事件 | 每个交易对 / 产品的 listing 记录，例如 spot、perp、不同报价币种 | 衡量交易所“公告 / 市场开放”的频率，但同一 token 可能有多条记录 |
| token 级上新 | 某个 base symbol 在该交易所 listing 历史中首次出现 | 更接近“新币上线”概念 |
| 交叉上新 | 同一归一化 token 符号在多家交易所首次出现 | 衡量多交易所扩散速度 |
| 产品范围 | spot、perp 均纳入；Binance Alpha 未并入 Binance 主站口径 | 避免把展示型 / Alpha 资产混入主站上币 |

注意：这是**符号级**统计，不是合约地址级统计；对 `1000PEPE / PEPE` 这类永续合约单位前缀做了归一化，但同名 token、旧币新增报价对仍可能带来少量噪声。

## 上币频率

**Bybit 是 token 级最激进的上新平台，Binance 是交易对 / 产品事件最多的平台。** Binance 过去 5 年有 **1,849 条** pair / product listing 事件，明显高于其他交易所；但若看 token 级首次上新，Bybit 以 **883 个**领先，是 Binance 的约 **1.9 倍**。

| 交易所 | Pair / Product 上币事件 | 月均事件 | Spot / Perp 事件 | Token 级首次上新 | 月均新 token | 新 token 中位间隔 | 读法 |
|---|---:|---:|---:|---:|---:|---:|---|
| Coinbase | **635** | 10.6 | 635 / 0 | **386** | 6.4 | 1.0 天 | 全 spot，偏合规筛选与确认 |
| Binance | **1,849** | **30.8** | 1,482 / 367 | **459** | 7.6 | 1.0 天 | 交易对 / 报价扩展最多，spot 仍占主导 |
| OKX | **1,003** | 16.7 | 696 / 307 | **409** | 6.8 | 1.0 天 | 2025-2026 明显加速，spot / perp 都活跃 |
| Bybit | **1,439** | 24.0 | 669 / 770 | **883** | **14.7** | **0.9 天** | 最激进，perp-first 比例高，发现属性强 |
| Upbit | **665** | 11.1 | 665 / 0 | **235** | 3.9 | 3.8 天 | 全 spot，选择性强，更像区域流动性确认 |

产品结构上也有明显差异：Coinbase / Upbit 在样本中是 **spot-only**；Binance 的 token 首次上新中约 **67.5%** 是 spot-first、**32.5%** 是 perp-first；OKX 约 **58.4%** spot-first、**41.6%** perp-first；Bybit 则是 **53.8% perp-first**，说明它更常用永续合约先捕捉新资产热度。

## 上币周期

过去 5 年的周期不是固定“月度上币”，而是**TGE / 叙事热度驱动的批量上新**。事件级中位间隔经常接近 0，是因为同一天会开放多个报价对；token 级看更清楚：除 Upbit 外，Coinbase、Binance、OKX、Bybit 的新 token 中位间隔都接近 **1 天**。

几个周期特征很明显：

1. **2024 是再加速起点，2025 是全面扩张年。** Bybit 从 2023 年 **116** 个新 token 升至 2024 年 **202**、2025 年 **218**；Upbit 也从 2024 年 **38** 跳到 2025 年 **87**。
2. **2026 年 OKX 提速最明显。** 截至 8 月 10 日，OKX 已有 **158** 个 token 级首次上新，超过其 2025 全年 **99** 个。
3. **工作日效应很强。** 五家合计看，新 token 上新集中在周二至周五：周四 **24.2%**、周三 **20.5%**、周二 **19.7%**、周五 **18.7%**；周六 + 周日合计只有 **3.7%**。
4. **爆发月比均值更重要。** 典型峰值包括 OKX **2026-07：79** 个新 token、Bybit **2026-06：46**、Binance **2026-07：44**、Coinbase **2022-06：34**、Upbit **2025-09：26**。
5. **低频交易所有更长空窗。** 样本内最长 token 上新空窗：Upbit **97 天**、OKX **88.9 天**、Coinbase **77.9 天**、Binance **74.4 天**、Bybit **44.0 天**。

## 交叉上新

**交叉上新的核心是 Bybit / OKX / Binance 的高频联动，Coinbase / Upbit 更常出现在确认阶段。** 五家合计去重后有 **1,323 个**新 token 符号，其中 **558 个**被至少两家交易所上新，占 **42.2%**。

## 交易含义

**上币 alpha 的顺序应按“早期发现 -> 流动性确认 -> 区域确认”来拆。** 如果只看单一交易所公告，容易错过真正的扩散路径。

1. **早期发现层：Bybit、OKX、Binance perp。**  
   Bybit 在交叉上新中领先 **240 次**，且 token 首次上新里 **53.8%** 是 perp-first；OKX / Bybit 的共同上新中位时差只有 **9.0 天**。这类信号适合追踪“资产是否进入全球衍生品视野”，但不等于低风险买点。
2. **主流确认层：Binance spot、Coinbase spot。**  
   Binance 的 pair / product 事件最多，说明其报价、产品和流动性扩展能力强；Coinbase 全部是 spot，且与 Bybit / Coinbase、Binance / Coinbase 的交叉中位时差通常超过 **100 天**，更像后验确认，而不是最早发现。
3. **区域确认层：Upbit。**  
   Upbit 新 token 数较少，但与其他交易所的重合率非常高：其 **235** 个 token 级首次上新中，约 **221 个**也出现在其他四家之一，重合率约 **94%**。这意味着 Upbit 更少孤立上新，更像“韩国现货流动性确认”信号。
4. **级联窗口：重点看 7 天、30 天、90 天。**  
   多交易所交叉上新的 **558** 个 token 中，**192 个**在 30 天内完成其多交易所扩散，**261 个**在 90 天内完成。若一个新资产先被 Bybit / OKX / Binance 之一上新，再在 7-30 天内被第二家确认，后续进入更广泛 CEX 池的概率通常更值得跟踪。
5. **不要机械追“全交易所同日上”。**  
   APT、MOVE 这类 1-2 天内五家齐上的资产，说明共识强，但也意味着 listing premium 很可能被快速定价。更好的交易框架是同步看现货深度、永续资金费率、OI、解锁 / TGE 流通量，而不是只看“又上了一家”。

## 结论

过去 5 年，CEX 上币结构已经变成三层：**Bybit / OKX / Binance 负责更快捕捉新叙事，Binance / Coinbase 负责更强的主流确认，Upbit 负责区域现货流动性确认**。频率上，Bybit 最激进；事件数上，Binance 最大；趋势上，OKX 2026 提速最明显；交叉上新上，Bybit 与 OKX / Binance 的联动最紧。

**底线。** 如果你要做上币监控，优先级应是：先盯 **Bybit / OKX / Binance 的 perp / spot 首发**，再看 **7-30 天内是否被第二家主流交易所确认**，最后把 **Coinbase / Upbit** 作为更强但更滞后的确认信号。
