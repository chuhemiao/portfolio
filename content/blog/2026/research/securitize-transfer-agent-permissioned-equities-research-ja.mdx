## TL;DR

**Securitize は本シリーズで初めて、保有者が実際に株主権を保持する発行体です。** 配当も議決権も完全です。理由は商品設計の優劣ではなく、**法的身分** —— 米国の**トランスファーエージェント（名義書換代理人）**であることです。

代償も明確です。**株式銘柄は 3 本、規模 $2.783 億、パーミッションレスは「否」、DeFi は利用不可。**

**判断としては、同社はリテール市場にいません。Ondo や xStocks と同じ規模表に並べること自体が分類の誤りです。** 機関投資家向けの一次市場インフラです。

**もう一つ正しておくべき数字があります。** Securitize の $38.8 億という TVL の大半は BUIDL などのファンドであり、**株式ではありません**。これを Ondo と「株式 TVL」で比較するのは、Ondo の $35.6 億（大半が国債商品）を使うのと同じ誤りです。

## トランスファーエージェントという身分の意味

Securitize を理解する鍵であり、本シリーズで初めて現れる本質的な法的差異です。

**トランスファーエージェントは米国証券法に基づく登録主体**で、証券保有者名簿の維持、名義書換の処理、配当の分配、コーポレートアクションと議決資料の伝達を担います。

**端的に言えば、「誰がその株を保有しているか」の公式記録そのものです。**

したがって Securitize が株式をトークン化するとき、既存の記録の外に影の証書を作っているのではありません。**自らが元々維持している名簿を、ブロックチェーン上で書き直しているのです。** トークン保有者は法的に株主です。株主名簿を維持する主体がそう記録しているからです。

先行する各社との比較：

| 発行体 | 身分 | トークンと名簿の関係 |
|---|---|---|
| xStocks | ジャージー島 SPV | カストディアンが株を保有、トークンは SPV の債務証券 |
| Ondo | BVI 法人 | トークンと担保株は**別の資産** |
| bStocks | ADGM 発行体 | 1:1 保管、トラッカー証券 |
| **Securitize** | **米国トランスファーエージェント** | **トークンが名簿の記載そのもの** |

**だからこそ完全な配当と議決権を提供でき、他社にはできません。** 意思の問題ではなく身分の問題です。Ondo は Broadridge を接続して初めて議決権を通せ、Robinhood は発行構造を再設計して初めて 1:1 償還ができます。Securitize は追加で何もする必要がありません。元々記録層に立っているからです。

## 代償：パーミッションレスは「否」

完全な権利は無料ではありません。

- **パーミッションレス：否**
- **DeFi 制限あり**
- 銘柄：**3 本**
- 規模：**$2.783 億**（2026-09-04 基準、シェア 10.1%）
- チェーン：Solana

**米国証券法の下では、株主名簿上のすべてのアドレスが既知の適格主体でなければなりません。** これはトランスファーエージェントであることの直接的な帰結です。適格な名簿を維持しながら、任意の匿名アドレスの自由な出入りを許すことはできません。

結果として：

- Uniswap のプールに入れない（プールアドレスは適格保有者ではない）
- Aave の担保にできない（清算で任意の清算人へ資産が移る）
- 友人に自由に送れない

**これは Coinbase の稿の結論と正確な鏡像です。** Coinbase の $750 万が Aave の担保になり Morpho で借入できるのは、まさにトランスファーエージェントではなく名簿義務を負わないからです。

**この分野の根本的な緊張はここにあります。完全な権利とコンポーザビリティは、現状では両立しません。**

| | 完全な株主権 | DeFi コンポーザビリティ |
|---|---|---|
| Securitize / Superstate | ✅ | ❌ |
| Coinbase | ❓（未検証） | ✅ |
| xStocks / Ondo / bStocks | ❌ | 部分的 |

**この排他性を先に破った者が次の段階を定義します。** SEC のイノベーション免除が認める**許可制 AMM 流動性プール**は、**まさにこれを破るために設計されています**。プール自体が許可制で、内部のアドレスはすべて検証済みであれば、適格な名簿と AMM が共存できます。

**Securitize はそのルールを最初に使う可能性が最も高い存在です。** 名簿は既にあり、足りないのは適格なプールだけだからです。

## 誤用される TVL の数字

独立した節に値します。

Securitize について引用される数字は通常 **$38.8 億の TVL** ですが、**株式事業は 3 銘柄・$2.783 億**です。

差額の大半は **BUIDL などのファンド商品** —— トークン化されたマネーマーケットおよび国債エクスポージャーであり、まったく別の資産クラスです。

**$38.8 億を使ってトークン化株式の首位を論じると順位が逆転し、その逆転した答えは誤りです。**

同じ罠は本シリーズで三度現れました。

1. **Ondo** の $35.6 億のプロトコル TVL、大半は USDY / OUSG の国債商品
2. **Robinhood** の四半期純利益 $5.61 億、株式トークンの寄与はほぼゼロ
3. **Securitize** の $38.8 億 TVL、大半は BUIDL などのファンド

**三つとも同じ誤り、より広い基準の数字を一事業部門の代理として使うことです。** 比較の前に基準を固定すること —— この分野の資料を読むうえで最も有用な規律と言ってよいでしょう。

## 検証できなかったもの

明示します。

1. **3 銘柄の具体名** — 資料に列挙なし
2. **償還条件** — 最低額、KYC の範囲、決済日数
3. **準備金証明** — トランスファーエージェントでは名簿自体が証明たりうるが、記述が見当たらない
4. **10 月基準の最新規模** — 最新資料の発行体表に単独掲載なし、$2.783 億は 9 月の数字
5. **参入要件** — どこまで許可制か。機関限定か、適格投資家も可か

**五番目が最も重要です。** 機関限定ならリテールには無関係であり、適格投資家も可なら Dinari の直接の競合になります。

## リスク

| 項目 | 程度 | 内容 |

| 規模データが古い | 中 | $2.783 億は 2026-09-04 基準、10 月資料に単独掲載なし |
| 銘柄が極端に少ない | 中 | 3 本では配分手段にならない |
| DeFi 利用不可 | 中 | 許可制の直接的帰結であり欠陥ではないが用途を制限 |
| 参入要件が不明 | 中 | 機関限定か適格投資家可かで関連性が変わる |
| 基準が誤用されやすい | 低 | $38.8 億の TVL が株式規模として引用されがち |

## 注視する点

1. **最初の TSV になるか** — 名簿があり適格プールのみ不足、最短経路
2. **許可制 AMM プールが実装されるか** — 権利とコンポーザビリティの排他性を破る唯一の既知経路
3. **3 銘柄からどこまで広がるか** — 現状ではリテールへの本気度を判断できない
4. **参入要件が適格投資家まで下りるか** — Dinari と競合か補完かを決める
5. **$38.8 億を株式規模として比較する資料がまだあるか** — 資料の信頼性を測る簡便な試金石

---

**結論。** Securitize は本シリーズで最も根本的な問いに答えています。**完全な株主権は実現可能であり、条件はパーミッションレス性を手放すことです。** コンポーザビリティが実現できないのではなく、法的身分がそれを許さないのです。

**問うべきは「なぜ Securitize はこんなに小さいのか」ではなく、「いつ許可制 AMM プールで両方を同時に成立させるのか」です。** それまでは機関インフラであり大半の読者には無関係ですが、この分野の権利の上限を定義しているのは同社です。
