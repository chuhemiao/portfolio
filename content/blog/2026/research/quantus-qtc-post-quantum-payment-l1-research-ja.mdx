## TL;DR

Quantus は、**ポスト量子セキュリティー、プライバシー決済、Proof of Work** を掲げる新しい Layer 1 です。量子計算の脅威は実在する問題であり、技術構成も単なる宣伝を超えています。取引署名に ML-DSA、ノード通信に ML-KEM、プライバシー取引の集約に ZK Wormhole を使います。

ただし **2026-10-12 UTC 時点**では、**メインネット稼働から約1か月の、リスクの高い初期プロトコル**です。主な懸念は、ポスト量子アルゴリズムの有無ではありません。

1. **ネットワーク効果と長期的な利用需要が未検証**。
2. **$QTC の流通量は最大供給の約1.33%**。
3. **ジェネシス供給の27%に投資家、チーム、会社向け配分が含まれ**、将来のアンロック圧力が大きい。
4. 流動性は NEAR Intents など初期の入口に集中し、板の厚みや複数取引所での吸収力は限られる。
5. ZK 回路、PoW、クロスチェーン MPC、プライバシーモデルは、より長い実運用での検証が必要。

私の判断は、**技術的には追跡する価値があるが、成熟した「量子リスクへの避難資産」とはまだ言えない初期の実験的ネットワーク**です。高リスクの少額観察枠には向いても、資産配分の中核には向きません。

## 位置付け：実在する課題と限定された製品範囲

Quantus は Ethereum や Solana のような汎用スマートコントラクト基盤ではありません。白書では、Bitcoin、Monero、Zcash に近い「量子時代の電子現金」と位置付けています。中心は**価値の移転、プライバシー、自己管理、耐量子署名**であり、DeFi、NFT、汎用アプリケーションのエコシステムではありません。[Quantus Whitepaper](https://www.quantus.com/whitepaper/)

| 項目 | 現在の設計 |
|---|---|
| 種類 | ポスト量子セキュリティーを備えた決済型 Layer 1 |
| コンセンサス | Poseidon2 ベースの Proof of Work、QPoW |
| ネイティブ資産 | $QTC |
| 最大供給 | 21,000,000 $QTC |
| スマートコントラクト | 汎用スマートコントラクトチェーンではない |
| プライバシー | Wormhole アドレスと ZK 証明集約 |
| メインネット | 2026-09-09 に稼働開始 |
| 主な流通経路 | NEAR Intents、Near.com、関連エコシステム |

投資仮説の中心は、次のアプリケーション基盤になることではありません。

> 量子計算が Bitcoin や Ethereum の楕円曲線署名を徐々に脅かすなら、市場はネイティブなポスト量子資産に先回りしてプレミアムを払うだろうか。

この仮説には一定の合理性があります。既存チェーンが耐量子署名へ更新する場合も、ウォレット、取引所、クロスチェーン基盤の移行、失われた資産の移行不能など、調整の問題が残ります。Quantus はジェネシスからポスト量子暗号を採用するため、既存資産の大規模移行が不要です。

一方、市場の範囲は狭くなります。**成熟したアプリケーション群や長い分配の歴史がない決済資産を、耐量子性を理由に保有したい利用者がいることを証明する必要があります。**

## 技術構成：整った設計と ZK・実装の複雑さ

Quantus は ECDSA を Dilithium に置き換えるだけではなく、署名、ノード通信、ウォレット派生、プライバシー送金、拡張方法をまとめて変更しています。

### 中心となる技術

| モジュール | 方式 | 分析 |
|---|---|---|
| 取引署名 | ML-DSA-87 / Dilithium | NIST 標準の格子暗号署名。NIST Level 5 を目指す |
| P2P 暗号化 | ML-KEM-768 | ノード間の鍵共有と通信保護 |
| ZK ハッシュ | Poseidon2 | ZK 回路向けの最適化であり、それだけで「量子安全アルゴリズム」と同義ではない |
| プライバシー取引 | Wormhole アドレス、ZK 証明、Nullifier | burn-and-remint により送受信者の直接のオンチェーン関係を切断 |
| 証明システム | Plonky2 由来の再帰 STARK | 取引証明をバッチ集約 |
| コンセンサス | QPoW | Poseidon2 で nonce を探索。目標ブロック間隔は約12秒 |

公式資料では、ML-DSA-87 の署名は約 **4,627 bytes**、公開鍵は約 **2,592 bytes** です。Bitcoin 型 ECDSA の署名・公開鍵は数十 bytes 程度です。署名サイズの増大には、ZK 集約で対処する必要があります。[Post-Quantum Cryptography Docs](https://docs.quantus.com/deep-dives/pqc/)

公式が示す処理能力：

- 透明な ML-DSA-87 取引：約 **43 QTPS**。
- 現在の2層 ZK 集約：約 **430 QTPS**。
- 理論上限：約 **2,800 QTPS**。

これらは設計・試験上の指標であり、高負荷の開放ネットワークで長期検証された本番処理能力とは異なります。[Wormhole & ZK Scaling Docs](https://docs.quantus.com/deep-dives/wormhole/)

### プライバシーは完全な不可視性ではない

Wormhole の大まかな流れ：

1. 直接使用できない Wormhole アドレスへ資産を送る。
2. 対応する秘密情報を保有することを示す ZK 証明をローカルで生成する。
3. 複数の証明を再帰的に集約する。
4. 証明の提出後、新しい退出アドレスで資産を再発行する。

送受信者の直接の関連を隠せますが、公式ウォレットの説明では、**金額や一部のオンチェーン構造は見えるまま**です。プライバシーは確率的であり、絶対的ではありません。[Quantus Wallet](https://www.quantus.com/wallet/)

より正確には、次のように理解できます。

> 直接のアドレス関連を弱めても、金額、時刻、退出先、取引頻度、クロスチェーン行動に基づくメタデータ分析のリスクは消えない。

「完全匿名の現金」とは、なお距離があります。

### 確認が必要な技術上の不一致

技術ページや詳細資料では、すべての取引が ML-DSA-87 を使うことを強調しています。一方、現在の白書の手数料表には次が併記されています。

- ML-DSA-65 の透明取引。
- ML-DSA-87 の透明取引。
- 暗号化された取引。

取引種類、アカウント方式、プロトコル版の違いかもしれません。ただし、安全レベルと実際の QTPS は、宣伝ページだけでなく、現在のメインネット runtime とチェーン仕様を基準に評価する必要があります。[Quantus Whitepaper](https://www.quantus.com/whitepaper/) [QPoW Consensus Docs](https://docs.quantus.com/deep-dives/qpow/)

### 流動性と取引の入口

$QTC は2026年10月初旬に NEAR Intents / Near.com を通じて取引可能になりました。関連発表では、180種類以上の資産、30以上のチェーンから接続でき、当初は従来型の中央集権取引所への上場がなかったとされています。[The Quantum Insider](https://thequantuminsider.com/2026/10/07/quantus-launches-post-quantum-asset-qtc-on-near-com/)

CoinGecko は Near Intents の QTC/USDC を主なペアとして挙げ、Rhea Finance、BigONE も掲載しています。ただし、掲載されていることと、十分な板の厚みがあることは同じではありません。[CoinGecko — Quantus](https://www.coingecko.com/en/coins/quantus)

この構造には両面があります。

- **利点：** 新資産がクロスチェーン流動性へ接続するハードルを NEAR Intents が下げる。
- **懸念：** 集約型の入口は深い流動性を保証せず、少額の限界資金でも価格が大きく動く可能性がある。
- **重要な問い：** 単一のエコシステム入口に頼らず、複数の独立市場で安定した価格発見が成立するか。

NEAR 統合資料では MPC、クロスチェーン統合、テストネットが開発中または予定とされていますが、外部報道では Near.com での取引開始が発表されています。資料が更新に追い付いていない可能性があり、「稼働中の取引入口」と「監査済みの完全なブリッジ基盤」を分けて捉える必要があります。[NEAR Integration Docs](https://docs.quantus.com/deep-dives/near-integration/)

## 安全性、ガバナンス、主なリスク

多くの監査資源が投入されていますが、監査を受けたことはリスクの消失を意味しません。

### 監査の前向きな要素

白書では Neodyme、Eiger/Equilibrium、Hashcloak、Immunefi などの安全性評価が挙げられ、対象は次のとおりです。

- ML-DSA と HD wallet。
- Poseidon2 と QPoW。
- Wormhole ZK circuits。
- Substrate runtime とノード。
- NEAR MPC。
- チェーン全体の公開監査コンペ。

Immunefi にも複数の完了報告が掲載されています。[Quantus Immunefi Audit Competition](https://immunefi.com/audit-competition/audit-comp-quantus/information/)

### 監査範囲を読み解く

Equilibrium の公開事例では、82ページの監査が Wormhole pallet、ZK circuits、Poseidon、取引拡張、オンチェーンの基本要素を対象にしています。Poseidon gate のデシリアライズが runtime の範囲外アクセス panic を起こす問題も発見されました。[Equilibrium Quantus Audit](https://equilibrium.co/projects/quantus-audit/)

ただし、同じ事例では次の範囲外が明記されています。

- コンセンサス機構。
- 上流の Plonky2 コード。
- 主な対象は Quantus が追加・変更した部分。

Immunefi の既知の問題には次も含まれます。

- マイナーとノードの接続は、信頼されたネットワーク上で動く前提。
- 取引量の増加で ZK tree が現在の深さ上限に達する可能性があり、回路と runtime の更新が必要。
- 一部の Substrate ガバナンス動作は上流実装を継承。

監査の結論は、次のように捉えるほうが正確です。

> 中心的な構成要素は複数の専門的レビューを受けているが、コンセンサス、ブリッジ、本番ネットワークの安全性、ZK の長期的拡張性は引き続き検証が必要である。

### リスク一覧

| リスク | 重要度 | 理由 |
|---|---|---|
| ジェネシス供給とアンロック | 高 | 流通量が極めて少なく、供給拡大が現在の市場吸収力を大きく超える可能性 |
| PoW の安全性 | 高 | 運用履歴が短く、ハッシュレート、集中度、攻撃コストの公開検証材料が少ない |
| ZK 実装の複雑さ | 高 | 回路、再帰集約、Poseidon、runtime が大きな攻撃面を構成 |
| クロスチェーン MPC | 高 | NEAR が主要入口であり、監査と統合状態の追跡が必要 |
| プライバシー規制 | 中高 | 取引所、法域、適法な流通経路で制限される可能性 |
| 流動性集中 | 中高 | 出来高は厚い板を意味せず、スリッページが急拡大する可能性 |
| ガバナンス集中 | 中 | 初期は Technical Collective の権限が高く、DAO へ完全移行していない |
| 製品需要 | 高 | 汎用アプリケーション群がなく、需要がポスト量子通貨のテーマに依存 |

### 三つのシナリオ

**強気シナリオ：**

- NEAR Intents が安定した流通経路になる。
- 複数のウォレットや取引基盤が $QTC に対応する。
- 実際の取引量でも ZK 集約が安定する。
- マイナー、ハッシュレート、アカウント活動が継続的に増加する。
- ポスト量子セキュリティーが主流の市場テーマになる。

この場合、ポスト量子・プライバシー・PoW という分野の代表資産になる可能性があります。

**基本シナリオ：**

- メインネットは正常に動くが、利用者は主にマイナー、投機家、初期のプライバシーコイン参加者。
- 価格はテーマの循環に大きく左右される。
- NEAR は取引入口を提供しても、強いネットワーク効果は生まれない。
- 2027年のアンロック接近で、供給リスクによる評価の割引が生じる。

現時点では、このシナリオの可能性が比較的高いと考えます。

**弱気シナリオ：**

- プライバシー需要が継続的なオンチェーン活動へつながらない。
- NEAR エコシステムから流動性が流出する。
- ZK、ブリッジ、ノードで安全性事故が発生する。
- ハッシュレートが不足する、または過度に集中する。
- アンロックとマイナー売却が市場の吸収力を超える。

その場合、$QTC はポスト量子資産から、低流動性のテーマトークンへ急速に変わり得ます。

## 結論

Quantus の利点は、存在しない課題を作り出しているわけではないことです。**量子計算による楕円曲線暗号への長期的な脅威は実在し、既存チェーンの移行にも調整コストがあります。**

技術構成は比較的整っており、すでに次が存在します。

- 稼働中の PoW メインネット。
- ML-DSA と ML-KEM。
- ZK Wormhole のプライバシーモデル。
- 公開コード。
- 複数回の第三者監査。
- NEAR Intents の流通・流動性入口。

ただし、中心的な課題は明確です。

> ジェネシスからポスト量子チェーンを作る方法は示したが、十分な人数が長期利用し、保有する理由はまだ証明していない。

技術上の希少性はネットワークの希少性に、ネットワーク活動は安定した需要に、まだ転換していません。低流通量による値上がりも、広い採用と同じではありません。

追跡すべき五つの指標：

1. **2027年のアンロック前後の保有分布と売却圧力**。
2. **マイナー数、ハッシュレート、難易度、集中度**。
3. **NEAR 以外に、十分な深さのある市場が生まれるか**。
4. **Wormhole 取引数、手数料、バーン量が増加するか**。
5. **ZK、MPC、runtime、コンセンサスの監査指摘に明確な修正記録があるか**。
