## 经济性 / 价值捕获

经济问题不是“协议是否合理”，而是“价值归属何处”。报告跟踪五种潜在价值归属渠道：

| 价值归属渠道 | 对 QAIT 的作用 | 所需证据 |
|---|---|---|
| 手续费 / 收入 | 披露核实前不清晰 | 协议手续费看板、财库报告、Token Terminal、DefiLlama 手续费 |
| 质押 / 安全 | 取决于 QAIT 是否锁定或可罚没 | 质押合约、验证者文档、奖励计划 |
| 抵押 / 生产性资产 | 被接受为抵押品或金库份额时有意义 | 借贷市场、风险参数、发行方文档 |
| 治理 / 发行控制 | 控制激励或风险时为中等 | 论坛提案、投票参与、管理员时间锁 |
| 回购 / 销毁 / 分配 | 明确且有资金支持时才强 | 官方机制、链上执行、财库来源 |

第一个分析框架是实用性的持久性。不能仅因为 QAIT 出现在 CoinGecko 或 CoinMarketCap 的发现列表中，就认为它值得投资。真正的问题是协议是否掌握可重复发生的工作流程：验证者需要分布式运营，贷方需要抵押流动性，LP 需要路由，代币化资产需要合规通道，或存款者需要收益。本报告的基本假设是 QAIT 属于DeFi 基础设施类别。因此，如果项目有代币，应根据代币是否直接捕获手续费、安全需求、抵押需求、风险管理需求、治理权或分发渠道来评价。无法转化为手续费的高 TVL，不如 TVL 较小但用户黏性强、收入清晰且发行量可控的项目。

第二个框架是流动性质量。当前跟踪的市场数据为：市值 $7.71M、FDV $48.46M、24h 成交量 $157.44K、价格 $0.0073、流通供应量 1.05B、总供应量 6.60B。这些数字本身不是买入信号，而是风险指标。如果 FDV 显著高于市值，后续解锁可能吸收需求，应下调上涨预期。如果成交量相对市值较低，仓位规模难以安排，应下调可交易性评价。如果价格强而项目使用量持平，应将行情视为叙事带来的贝塔，而非基本面重估。如果使用需求持久但价格弱，应列入观察名单，而非立即做多。

第四个框架是价值捕获。DeFi 基础设施资产可以有用，而代币依然弱。报告因此区分产品与市场匹配和代币与市场匹配。前者考察激励减少后用户是否仍需要协议；后者考察代币是否通过质押、手续费路由、抵押、治理约束、发行控制、罚没保险或专属访问权吸收价值。如果代币主要用于治理，基准情景应降低信心。如果代币用于安全或手续费捕获，但机制尚未启动，则把价值捕获视为未来选项，而非当前现金流。

第五个框架是反身性。许多 DeFi 与基础设施资产分阶段重估：先是 TVL 和上市，随后是手续费可见性、代币经济改善，最后是真实现金流或战略收购叙事。QAIT 应沿此顺序持续观察。可用的 90 日 TVL 序列有 0 个数据点，最新 TVL 为 未披露，近似变化为 未披露。Surf 或 CoinGecko 有相应字段时，市场价格变化为 7d -15.39%、30d -74.07%。TVL 与价格同向变化可能只是贝塔效应；TVL 上升而价格滞后，意味着市场质疑价值捕获；价格上升而 TVL 下降，则是缺乏基本面确认的动量。

保守结论是 QAIT 的产品重要性可能领先于代币价值捕获，这在该领域很常见。因此应关注启动事件：手续费开关、质押重构、收入看板、额度上调、重大集成或发行减少。

关键竞争问题是 QAIT 是否有超越激励的存在理由。如果转换成本低、用户主要追逐发行奖励，估值溢价应视为暂时。如果协议掌握稀缺集成点、合规通道、验证者层或流动性场所，可能值得持续的观察溢价。

## 催化因素

| 催化 | 乐观解读 | 监测证据 |
|---|---|---|
| 新上市或交易所深度增加 | 流动性与访问范围改善 | CEX 公告、CMC 市场页面、订单簿深度 |
| 手续费 / 收入看板 | 代币捕获可测量 | DefiLlama 手续费、Token Terminal、财库报告 |
| 质押或治理升级 | 需求更少依赖投机 | 治理提案、合约部署 |
| 协议集成 | 分发超出核心用户 | 合作方文档、实际集成、活跃地址 |
| 风险披露或审计 | 下行风险更容易评估 | 审计、事件复盘、漏洞赏金范围 |
| 发行减少 | 卖压下降 | 代币经济更新、链上解锁时间表 |

短期催化应视为监测触发因素，而非预测。本报告最有用的催化是出现能够把代币从叙事敞口转化为可测量价值捕获的来源。

## 流动性、仓位与退出纪律

流动性连接研究与投资组合构建。QAIT 可能值得关注，但仓位与退出能力取决于 QAIT 市场的质量。报告 24h 成交量为 $157.44K 的代币，如果成交量分散、集中于低质量场所或来自浅薄做市，也可能难以交易。因此不能仅用表面成交量判断可交易性。更可靠的流程是查看 CEX 订单簿、DEX 池及其资产构成、跨链桥深度、稳定币路由，以及 CMC 与 CoinGecko 列出的主要场所。

仓位规则首先是滑点。正常规模的交易会推动价格时，即使叙事良好，也只应观察或持有极小仓位。其次是解锁风险。FDV 远高于市值或发行仍高时，估值折价不可省略。第三是催化时点。上市、集成或代币经济更新带来事件风险；审计、治理投票或攻击后恢复则带来二元下行风险。第四是相关性。市场风险偏好上升时，许多DeFi 基础设施代币会一起波动，因此应合并计算相关仓位的类别敞口。

QAIT 当前应优先作为观察对象。市值 $7.71M、FDV $48.46M、报告 24h 成交量 $157.44K、FDV / 市值 6.29x。这些数值可以支持研究卡片，但不会自动支持投资。更理想的条件包括多场所成交量稳定、价差窄、较少依赖单一交易对，以及不会形成近期集中解锁压力的供应计划。

## 持币者价值捕获检验

代币持有者检验应比产品检验更严格。有用的协议也可能是差的代币投资。QAIT 出现在 CG/CMC 候选流程中，且有足够可见数据支持完整报告，因此达到产品关注门槛，但尚未达到高确信度的持币门槛。QAIT 要达到更高标准，需要一个或多个可测量的价值捕获渠道。最强的是由真实协议收入支持的直接手续费分配或回购；其次是无法被替代的质押或抵押需求。较弱的渠道包括激励治理、品牌敞口或未来可能转化为价值的生态积分。

应依次检验代币价值捕获：首先识别全部协议收入及其接收者；其次确认持币者是否控制、接收、承保或抵押该收入；第三确认机制已在运作，还是仅有提案；第四对比预期代币需求与预期发行、解锁和财库卖出；第五检查用户是否可绕开代币使用产品。如果不持有或使用 QAIT 也能获得产品的主要利益，则代币与市场匹配弱于产品与市场匹配。

## 最终投资观点

QAIT 应作为**观察 / 选择性尽调**资产列入 Research Map。项目的类别相关性与数据记录足以支持持续覆盖，尤其是它来自 CG/CMC 候选流程且本地没有高确信度重复条目。当前证据尚不足以支持高确信度配置。进一步提高信心，需要更清晰的代币经济：手续费捕获、质押或抵押用途、透明解锁，以及能够支持实际仓位规模的流动性。

最终观点：**观察，不自动买入**。上涨空间来自产品使用转化为代币需求；下行风险来自相反情况：产品存续，但持币者承受稀释、流动性薄弱和不清晰的价值捕获。
