## TL;DR

Quantus 是一个主打「**后量子安全 + 隐私支付 + Proof of Work**」的全新 Layer 1。它解决的量子计算威胁是真实问题，技术路线也比单纯营销叙事更完整：交易签名采用 ML-DSA、节点通信采用 ML-KEM、隐私交易通过 ZK Wormhole 聚合。

但截至 **2026-10-12 UTC**，Quantus 仍是一个**刚上线约一个月的高风险早期协议**。当前最大风险不是「有没有后量子算法」，而是：

1. **网络效应和长期用户需求尚未验证**；
2. **$QTC 流通量只有最大供给的约 1.33%**；
3. **27% 创世供给包含投资者、团队和公司分配**，未来存在较强解锁压力；
4. 流动性仍集中在 NEAR Intents 等早期渠道，深度和多交易所承接能力有限；
5. ZK 电路、PoW 安全性、跨链 MPC 和隐私模型仍需更长时间的实战验证。

我的判断是：**Quantus 是技术上值得跟踪、但目前还不能视为成熟「量子避险资产」的早期实验性网络。** 适合高风险观察仓，不适合作为核心资产配置。

## 项目定位：真实痛点，窄产品路线

Quantus 并不是 Ethereum、Solana 类型的通用智能合约平台。官方白皮书将它定位为更接近 Bitcoin、Monero 或 Zcash 的「面向量子时代的电子现金」，核心功能是**价值转移、隐私、自托管和抗量子签名**，而不是 DeFi、NFT 或通用应用生态。[Quantus Whitepaper](https://www.quantus.com/whitepaper/)

| 维度 | Quantus 当前设计 |
|---|---|
| 项目类型 | 后量子安全支付型 Layer 1 |
| 共识 | QPoW，基于 Poseidon2 的 Proof of Work |
| 原生资产 | $QTC |
| 最大供给 | 21,000,000 $QTC |
| 智能合约 | 非通用智能合约链 |
| 隐私方式 | Wormhole 地址 + ZK 证明聚合 |
| 主网 | 2026-09-09 上线 |
| 主要分发渠道 | NEAR Intents、Near.com 及相关生态 |

项目的核心投资逻辑不是「Quantus 会成为下一个应用平台」，而是：

> 如果量子计算逐步威胁 Bitcoin、Ethereum 等链的椭圆曲线签名，市场是否会提前为原生后量子资产支付溢价？

这个逻辑有一定合理性。传统链即使未来升级到抗量子签名，也要面对钱包迁移、交易所升级、跨链基础设施迁移以及丢失资产无法迁移等协调问题。Quantus 的优势在于它从创世阶段就采用后量子密码学，不需要对存量资产进行大规模迁移。

但这也意味着它的市场空间相对狭窄：**它必须证明用户愿意持有一种没有成熟应用生态、没有长期分布历史、但具有抗量子特性的支付资产。**

## 技术架构：设计完整，但复杂度集中在 ZK 和实现层

Quantus 的技术栈不是简单地把 ECDSA 换成 Dilithium，而是同时替换交易签名、节点通信、钱包派生、隐私转账和扩容机制。

### 核心技术组件

| 模块 | Quantus 方案 | 分析 |
|---|---|---|
| 交易签名 | ML-DSA-87 / Dilithium | NIST 标准化的格密码签名，目标为 NIST Level 5 |
| P2P 加密 | ML-KEM-768 | 用于节点间密钥协商和通信保护 |
| ZK 哈希 | Poseidon2 | 面向 ZK 电路优化，不等同于「量子安全算法」 |
| 隐私交易 | Wormhole 地址、ZK 证明、Nullifier | 通过 burn-and-remint 切断发送者与接收者的直接链上关系 |
| 证明系统 | Plonky2 派生的递归 STARK | 用于批量聚合交易证明 |
| 共识 | QPoW | 用 Poseidon2 进行 nonce 搜索，目标区块时间约 12 秒 |

官方文档披露，ML-DSA-87 的签名约 **4,627 bytes**，公钥约 **2,592 bytes**，而 Bitcoin 类 ECDSA 签名和公钥仅约几十 bytes。Quantus 需要依靠 ZK 聚合来解决签名膨胀问题。[Post-Quantum Cryptography Docs](https://docs.quantus.com/deep-dives/pqc/)

官方给出的吞吐指标是：

- 透明 ML-DSA-87 交易：约 **43 QTPS**；
- 当前两层 ZK 聚合：约 **430 QTPS**；
- 理论上限：约 **2,800 QTPS**。

需要注意，这些是协议设计和测试口径，不等于已经在高负载、开放网络环境下被长期验证的生产吞吐量。[Wormhole & ZK Scaling Docs](https://docs.quantus.com/deep-dives/wormhole/)

### 隐私不是绝对隐身

Quantus 的 Wormhole 机制大致是：

1. 用户将资产发送至不可直接消费的 Wormhole 地址；
2. 用户在本地生成 ZK 证明，证明自己拥有对应秘密；
3. 多个证明被递归聚合；
4. 证明提交链上后，在新的退出地址重新铸造资产。

它可以隐藏发送者与接收者之间的直接关联，但官方钱包说明显示，**金额和部分链上结构仍然可见**，隐私具有概率性而非绝对性。[Quantus Wallet](https://www.quantus.com/wallet/)

因此，Quantus 的隐私模型更准确的表述是：

> 它降低直接地址关联，但不能消除金额、时间、退出地址、交易频率和跨链行为带来的元数据分析风险。

这与「完全匿名现金」仍有距离。

### 一个需要确认的技术不一致

官方技术页面和深度文档主要强调所有交易使用 ML-DSA-87，但当前白皮书的手续费表同时列出了：

- ML-DSA-65 透明交易；
- ML-DSA-87 透明交易；
- 加密交易。

这可能代表不同交易类型、不同账户模式或协议版本，但在评估安全等级和实际 QTPS 时，应以当前主网 runtime 和链规范为准，而不能只依据营销页面的单一表述。[Quantus Whitepaper](https://www.quantus.com/whitepaper/) [QPoW Consensus Docs](https://docs.quantus.com/deep-dives/qpow/)

### 流动性和交易入口

$QTC 于 2026 年 10 月初通过 NEAR Intents / Near.com 开放交易。项目相关披露称，用户可以通过 180 多种资产、30 多条链接入 $QTC，且初期没有传统中心化交易所挂牌。[The Quantum Insider](https://thequantuminsider.com/2026/10/07/quantus-launches-post-quantum-asset-qtc-on-near-com/)

CoinGecko 当前页面将 Near Intents 的 QTC/USDC 列为主要交易对，并另外列出 Rhea Finance 和 BigONE，但这并不等于所有市场都拥有足够的订单簿深度。[CoinGecko — Quantus](https://www.coingecko.com/en/coins/quantus)

这带来两面性：

- **正面：** NEAR Intents 降低了新资产获取跨链流动性的门槛；
- **负面：** 聚合交易入口不等于深度流动性，价格可能被少量边际资金显著推动；
- **关键问题：** $QTC 是否能在多个独立市场形成稳定价格发现，而不是依赖单一生态入口。

值得注意的是，NEAR 集成文档仍将 MPC、跨链集成和测试网描述为开发中或计划阶段，而外部新闻已经披露 QTC 在 Near.com 上线。这说明项目文档存在滞后，投资者需要区分「已上线的交易入口」和「完整、经过审计的桥接基础设施」。[NEAR Integration Docs](https://docs.quantus.com/deep-dives/near-integration/)

## Tokenomics 与估值：真正的短期核心风险

Quantus 的供给模型兼具 Bitcoin 式硬上限和较高创世分配，两者之间存在明显张力。

### 供给结构

当前白皮书披露：

- 最大供给：**21,000,000 $QTC**；
- 创世阶段一次性铸造：**27%，即 5,670,000 $QTC**；
- 投资者、创始人和团队：**23%，即 4,830,000 $QTC**；
- 公司分配：**4%，即 840,000 $QTC**；
- PoW 未来挖矿释放：**73%，即 15,330,000 $QTC**；
- 公司 4% 中，约 **1% 在创世阶段可流通**，剩余 3% 锁定；
- 投资者、团队以及公司锁定部分在主网上线一年后开始，随后线性解锁 36 个月。

若按 $140.18 价格计算：

- 当前流通市值约为 **$39M**；

1. 市场能否吸收未来矿工排放；
2. 2027 年开始的投资者和团队解锁；
3. 早期持有人是否在流动性变差时集中卖出；

投资人阵容提高了项目可见度，但并不能替代真实用户、算力、隐私交易和跨市场流动性。

## 安全、治理与主要风险

Quantus 已经投入了相当多的审计资源，但「有审计」不等于「风险已经消失」。

### 安全审计的积极面

官方白皮书列出 Neodyme、Eiger/Equilibrium、Hashcloak 和 Immunefi 等安全工作，覆盖：

- ML-DSA 与 HD wallet；
- Poseidon2 和 QPoW；
- Wormhole ZK circuits；
- Substrate runtime 和节点；
- NEAR MPC；
- 全链公开审计竞赛。

Immunefi 页面也列出了多份已完成报告。[Quantus Immunefi Audit Competition](https://immunefi.com/audit-competition/audit-comp-quantus/information/)

### 审计范围仍需仔细解读

Equilibrium 的公开案例说明，其 82 页审计覆盖了 Wormhole pallet、ZK circuits、Poseidon、交易扩展和链上原语，同时发现过 Poseidon gate 反序列化导致运行时越界 panic 的具体问题。[Equilibrium Quantus Audit](https://equilibrium.co/projects/quantus-audit/)

但该案例页面也明确指出：

- 共识机制不在该审计范围内；
- 上游 Plonky2 代码不在范围内；
- 审计主要聚焦 Quantus 自己新增或修改的部分。

此外，Immunefi 页面列出的已知问题包括：

- 矿工与节点之间的连接被假定运行在可信网络中；
- 随交易量增长，ZK tree 深度可能达到当前限制，需要未来升级电路和 runtime；
- 某些 Substrate 治理行为沿用了上游实现。

因此，审计结论更准确的理解是：

> Quantus 的核心组件经过了多轮专业审查，但其共识安全、桥接安全、实际主网运行安全和长期 ZK 扩展性仍需要持续验证。

### 风险矩阵

| 风险 | 严重度 | 为什么重要 |
|---|---|---|
| 创世供给和未来解锁 | 高 | 当前流通量极低，未来供给扩张可能远超当前市场承接能力 |
| PoW 网络安全 | 高 | 主网历史短，公开可验证的算力、矿工集中度和攻击成本数据仍有限 |
| ZK 实现复杂度 | 高 | ZK 电路、递归聚合、Poseidon 和 runtime 共同构成较大攻击面 |
| 跨链 MPC | 高 | NEAR 是主要流动性入口，MPC 审计和完整跨链状态需要持续观察 |
| 隐私监管 | 中高 | 隐私交易可能面临交易所、司法辖区和合规入口限制 |
| 流动性集中 | 中高 | 早期交易量较高，但成交量不等于深度，滑点可能快速扩大 |
| 治理中心化 | 中 | Technical Collective 在早期承担高权限技术决策，DAO 尚未完全接管 |
| 产品需求 | 高 | 没有通用智能合约生态，长期需求高度依赖「后量子货币」叙事 |

### 三种情景

**乐观情景：**

- NEAR Intents 成为稳定分发入口；
- 多个钱包和交易平台接入 $QTC；
- ZK 聚合在真实流量下保持稳定；
- 矿工数量、算力和账户活跃度持续增长；
- 后量子安全成为主流市场主题。

在这种情况下，Quantus 可能成为「后量子 + 隐私 + PoW」这一细分赛道的代表资产。

**基准情景：**

- 主网能够正常运行，但用户主要是矿工、投机者和隐私币早期参与者；
- 价格受主题轮动影响大；
- NEAR 入口提供交易，但没有形成强网络效应；
- 2027 年解锁临近时，估值受到供给折价。

这是目前概率较高的情景。

**悲观情景：**

- 隐私需求无法转化为持续链上活动；
- 流动性从 NEAR 生态撤出；
- 出现 ZK、桥接或节点层面的安全事故；
- PoW 算力不足或过度集中；
- 解锁和矿工卖压超过市场承接能力。

在这种情况下，$QTC 可能从「后量子资产」迅速退化为低流动性叙事币。

## 结论

Quantus 的优势在于，它不是凭空制造一个不存在的问题：**量子计算对当前椭圆曲线密码体系的长期威胁是真实的，传统链的迁移也确实存在协调成本。**

同时，Quantus 的技术路线相对完整，已经有：

- 运行中的 PoW 主网；
- ML-DSA 和 ML-KEM 后量子密码体系；
- ZK Wormhole 隐私模型；
- 公开代码仓库；
- 多轮第三方审计；
- NEAR Intents 分发和流动性入口。

但当前的核心矛盾也很清楚：

> Quantus 解决了「如何从创世阶段构建后量子链」的问题，却还没有证明「为什么足够多的人会长期使用和持有这条链」。

在当前阶段，技术稀缺性还没有转化为网络稀缺性；网络活动还没有转化为稳定需求；低流通量带来的价格上涨也不能等同于广泛采用。

建议重点跟踪以下五个信号：

1. **2027 年解锁前后的链上持仓与卖压变化**；
2. **矿工数量、算力、难度和矿工集中度**；
3. **NEAR 之外是否出现真正有深度的交易市场**；
4. **Wormhole 隐私交易数量、费用和销毁量是否持续增长**；
5. **ZK、MPC、runtime 和共识审计问题是否全部有明确修复记录**。

**底线。** Quantus 值得作为后量子密码与隐私支付赛道的重点观察项目，但目前更像一项高风险基础设施投资，而不是已经完成产品市场验证的成熟货币网络；若参与，应以极小仓位、明确的解锁和流动性风险预算为前提。
