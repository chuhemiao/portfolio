## Resources to prepare
1. The server must support `https`, and the download source for each file must also use `https`.
2. Two PNG icons for the installed app: one `57*57` and one `114*114`.
3. The files to access can be placed among the resources on a `web` server and accessed directly.
4. The files are `autoninstall.html` and `dai.plist`. The download page is `https://idiot6.com/autoninstall.html` (this domain is a test address and is not accessible).
5. Configure the doLocation URL in autoinstall.html, and the `bundle-identifier`, images, and title in dai.plist.
6. A serious pitfall: plist files are cached. If an upgrade or faulty configuration has already gone live, create a new `plist` file and update its path in `autoinstall.html`.
7. The configuration files are shown below:

```html
<html>
<head>
<title>标题</title>
<meta http-equiv="Content-Type" content="text/HTML; charset=utf-8">
<meta http-equiv="pragma" content="no-cache">
<meta http-equiv="cache-control" content="no-cache">
<meta http-equiv="expires" content="0">
<meta content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=0;" name="viewport" />
<script type="text/javascript">
function doLocation(url)
{
  var a = document.createElement("a");
  if(!a.click) {
    window.location = url;
    return;
  }
  a.setAttribute("href", url);
  a.style.display = "none";
  document.body.appendChild(a);
  a.click();
}
</script>
</head>
<body>
<script type="text/javascript">
doLocation('itms-services://?action=download-manifest&url=https://idiot6.com/dai.plist');
</script>
</body>
</html>
```
