# Mac で react-native run-ios を実行すると CFBundleIdentifier", Does Not Exist が出る

1.原因：/Users/ユーザー名`/.rncache内の boost_1_63_0.tar.gz、double-conversion-1.1.5.tar.gz、folly-2016.09.26.00.tar.gz、glog-0.3.4.tar.gz が不完全。または node_modules/react-native/third-party` のファイルが不完全。
+ /user/ユーザー名/.rncache 内で削除する：`boost_1_63_0`。再びダウンロードしてインストールする
+ 端末を開き、プロジェクトのディレクトリで入力する：`rm -rf node_modules && rm -rf ~/.rncache && yarn`
+ `npm install`  
+ `react-native upgrade` 
+ 実行：`react-native run-ios`

2. [GitHub の回答](https://github.com/facebook/react-native/issues/7308) 。多くの賛同はパスの問題に関するものらしい。設定は本当に難しい！

3. それでも解決しなければ、削除してビルド環境からプロジェクトを作り直し、プロキシをグローバルモードにして実行する：`npm install`（または yarn）。グローバルモードで最新版の`react-native`では発生しなかった：`CFBundleIdentifier`の問題。
