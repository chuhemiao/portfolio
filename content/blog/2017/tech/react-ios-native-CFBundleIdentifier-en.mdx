# Running react-native run-ios on Mac returns CFBundleIdentifier", Does Not Exist

1.Cause: /Users/your-username`/.rncachecontains incomplete boost_1_63_0.tar.gz, double-conversion-1.1.5.tar.gz, folly-2016.09.26.00.tar.gz, or glog-0.3.4.tar.gz files. Or node_modules/react-native/third-party` files are incomplete.
+ Delete from /user/your-username/.rncache:`boost_1_63_0`, then download and install again
+ Open the terminal and run this in the project directory:`rm -rf node_modules && rm -rf ~/.rncache && yarn`
+ `npm install`  
+ `react-native upgrade` 
+ Run `react-native run-ios`

2. [GitHub discussion](https://github.com/facebook/react-native/issues/7308) : most upvotes seem to concern path problems. Configuration really is a headache!

3. If this still does not solve the problem, delete and regenerate the project with the build environment, then use a proxy in global mode for`npm install`(or use yarn). In global mode, the latest`react-native`did not produce a `CFBundleIdentifier`problem.
