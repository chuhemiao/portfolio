这里包含实质结论校正。原稿的看多设计偏好和低配发/高执行风险的研究方向保留，但“8.6倍优势”“市场已证明”“确定更便宜”不再作为已证结论。金额、原敏感性表及观察窗口继续可追溯，未来周度门槛作为条件观察点。
