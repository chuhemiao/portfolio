## 冻结任务

研究主持人向每位参与者给出下列问题，记录其选择的资料、允许公开的依据链接和证据边界。问题不要求读完资料，也不把编辑精选解释为外部作者推荐。

1. 找到 ERC-7702 的原始规范，并说明详情页的固定版本与阅读范围。
2. 找到一种与许可制 token 身份、转移资格有关的规范，区分接口说明与法律合规证明。
3. 找到 NFT 所有权与转移的资料，说明它能否独立证明实物托管或赎回保障。
4. 找到一篇 AMM 论文或白皮书，辨认其版本以及本资料库是否核读全文。
5. 找到一项关于二级市场或交易所的课程资源，将其保存、标为稍后阅读，再恢复到保存列表；指出视频是否托管在本站。

## 执行与记录

拟招募 20–30 人，由所有者安排真实参与者并取得同意。使用匿名研究编号；不收持仓、钱包、账号、原始自由搜索词或个人身份。不同参与者按 AB/BA 顺序交叉随机，五项任务采用轮转顺序平衡练习效应。A 为当前人工精选＋B1；B 必须在研究前明确冻结为参与者通常使用的检索方式，并记录工具、资源范围和版本。未有合法且可比的 B 条件时，只做可用性观察，不宣称排序优势或因果改善。

每题记录：匿名编号、条件与顺序、任务编号、开始/结束时间、完成/失败/放弃、所选资源 ID、来源可引用性、证据边界是否识别、操作困难和自报信心。由两名真实独立评审按相同 rubric 盲评；分歧交第三名裁决，保留原始判断。对任务时长只比较成功任务并同时报告失败率，避免把放弃误作加速。

五题后记录匿名条件偏好和理由；55% 是待测目标，样本不足仅作探索性结果。回访须另经参与者同意及明确观察窗口。没有实际数据时所有指标保持 `null/not-run`，不以 agent、多次模拟或功能测试充当参与者。

## 与离线协议的边界

`data/library/evaluations/human-protocol.v1.json` 已固定 120 个真实候选样本（每类 24），当前 raters、annotations、search_judgments 均为空。至少两名真实独立标注者完成成对标注后才能计算 κ；没有人类相关性判断就不计算 NDCG/Recall 或 verified precision。现有 108 组、324 个三语功能探针只证明明确的检索行为，不能充当金标准确率。

记录由研究负责人按同意范围留存；网站不新增事件、参与者后台或招募消息。研究材料准备不等于完整 G2/G4 实验通过，也不改变来源权利与发布资格门槛。
