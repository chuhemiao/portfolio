# M1 三语原创编辑说明与对比记录

本轮固定100项，五类各20项。每项已有中文、英文、日文标题、摘要、三段完整原创编辑说明和一条推荐理由。这里写的是本站阅读定位；没有翻译或复制受限的外部全文。300条候选与100条公开资格分开计数。

## 依据与范围

- 20份规范仅依据实际核读的固定版本章节，机制解释见原有 `spec-reading-facts.json`。正文保留 pin、核读章节、实现未验证和非安全审计边界；ERC-8004 明确为 Draft。
- 其余80项为 `metadata_only`，只据已核书目或官方目录写资源特定的阅读问题。未读论文摘要/全文、书籍简介/目录/全书、EF正文/图片、课程视频/字幕，未推定逐节讲者。
- 研究问题和推荐理由属于本站原创编辑选择，不是作者结论或社区背书。没有新建推荐证据、社区票数、外部引文或人类金标。
- [来源传输收据](source-transfer-receipts.json)逐包核验80项的count、bytes、SHA256；source key集合与固定选择精确一致。[逐项覆盖记录](coverage.json)连接100项来源、阅读范围、三语内容hash与保真自查程序。

## 中文检测与语义复核

使用 `lieflat-less-ai-tone` 的原始 `detect.py` 函数，保存[改前](chinese-detect.before.json)与[改后](chinese-detect.after.json)JSON；输入由300份基线中的中文字段重建，格式和SHA见[input manifest](chinese-input-manifest.json)。检测仅针对本站原创中文，未应用于英文、日文。

| 项目 | 改前 | 改后 | 处置 |
| --- | ---: | ---: | --- |
| 翻案、起手、当时从句、话题壳、句首连接词 | 各0 | 各0 | 无逐句修改项 |
| 提示语冒号 | 1 | 1 | Oracle标题中的「问题：」为题名结构，保留 |
| 顿号并列≥3 | 12 | 11 | 一处三问句调整；必要技术状态、模块、职责和条件保留 |
| 过长前置定语 | 1 | 2 | 同一句进入新摘要后多一次命中；算法把「把这个题名作为…入口」的动宾结构误读为定语，保留 |
| 中文分号 | 106 | 0 | 可独立陈述的分句改句号，不拆段，不删技术限定 |
| 破折号 | 0 | 0 | 不补写 |

改前约2.25万、改后约2.33万汉字，增量主要来自摘要明确范围。两轮文稿范围含摘要变化，指标差值不能全归于文风改善，也没有单篇统计显著性或作者来源鉴定。结构分布与引号等指纹保留原始结果，不为靠近某个数值制造长短句。

[正则命中去向](chinese-hit-decisions.json)保留全部原始命中和四项同义词误报。原始语义候选已用相同函数解除输出截断后完整保存：[改前831条](chinese-candidates.before.full.json)、[改后908条](chinese-candidates.after.full.json)。对应[改前判读](chinese-semantic.before.json)、[改后判读](chinese-semantic.after.json)使用技能的封闭标签；题名/书目/原文/本站指引不是同一实体反复改名，冒号为元数据用途，5组三句的主谓与论证功能不同。没有≥6接口连环或需要改写的结论冒号。正式术语引入、必要清单和证据边界否定均保留。

这些是实际Codex编辑自查记录。语义、自然表达和来源保真需要读文本；hash只用于绑定版本，不能代替语义审核。独立文本agent实际逐项读完100×3，只发现上述两处日文问题；修正与范围见[独立文本复核记录](independent-text-review.json)。两项item revision 2→3、六份locale revision 1→2/source_revision 2→3，理由ID、文字和依据不变，已用实际修订/复核/发布事件重绑。原有中文、英文正文、原metadata未改。最终差异共413条记录，含摘要整理，不等于413处语义错误。不宣称人类评审、法律顾问签字或用户实验已完成。
